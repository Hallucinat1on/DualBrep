# 网格粗加密与近场细加密：实施与验收

更新：2026-11-01。状态：两级加密已实现，完整同源 20 dev 新实验尚未启动。此前仅限时的单级细分批次已终止，产物、源码快照、性能探针和专用实验文档已清理；历史 MC 及原生四轮对照保留。

## 1. 目标与固定选择

流程改为：原始 condition 网格 → 纯几何粗加密 → E/V 查询 → 近场细加密 → 面分割、拓扑、共享几何与 STEP。

| 项目 | 决定 |
|---|---|
| 原始网格 | 保留作为模型 condition、坐标与 mesh SDF 基准 |
| 粗加密 | 全网格仅细分长度超过 0.02 的边，不查询 SDF/E/V，不移动原有顶点 |
| 细加密 | 沿用现有 E/V 近场选区，最长边目标 0.005 |
| 唯一新增剪枝 | 选中面只标记仍超过目标长度的边；共享边统一处理，邻面做必要过渡剖分 |
| 近场半径 | E=0.02、V=0.03，保持现有语义 |
| 时间 | 每例总超时 10800 秒，覆盖准备、两级加密、重建与评分 |
| 停止方式 | 两级分别达标后继续；不设置轮数、三角形数量或 RSS 硬上限 |

本次不加入更紧的 Lipschitz 下界、永久远场排除、额外主动队列、缩小近场半径、分级密度或共面重网格化。粗加密先降低三角形的空间跨度，细加密仅保留已有探针中收益更明显的超长边剪枝。

## 2. 两级加密规则

### 粗加密

对当前全网格建立共享边索引，标记 `edge_length > coarse_edge * (1 + 1e-10)`，使用现有支持 1/2/3 条切边的 red/green 规则剖分，直到全网格最长边不超过默认 0.02。已短于阈值的边不标记；细密曲面区域可直接保留。

粗加密是一个独立阶段，内部按达标条件迭代。它不使用 UDF 选区，不统一对所有三角形一分为四，不对顶点进行平滑或投影。新顶点取原共享边中点，保留原分片线性表面。

### 细加密

首次查询粗网格顶点与中心的 E/V。保留当前判断：对 present 通道，`min(vertex_udf) − longest_edge <= rho` 或 `center_udf <= rho` 时纳入近场；近场内最长边大于 0.005 的面继续细分。

唯一新增剪枝为：

```text
selected_face = near_field AND face_longest_edge > fine_edge
marked_edge = belongs_to_any(selected_face) AND edge_length > fine_edge
```

标记作用在全局共享边上。未选中的相邻面仍按共享边标记进行必要过渡剖分，保持闭合。每轮重新判断近场是否达标，未知或无效场值沿用现有失败语义；新增顶点与子面中心重新查询，不插值父场值或复制父标签。

原顶点场值继续复用。细加密最终已经查询的中心场值可直接交给 `build_bands`，减少阶段间完全相同的查询；这是字段复用，不添加新的空间剪枝规则。保持 fallback：独立调用 `build_bands` 时仍可自行查询。

## 3. 代码与产物

| 文件／模块 | 改动 |
|---|---|
| `bandbrep/config.py`、`configs/default.json` | 新增 `refinement_coarse_edge=0.02`；保留细目标、半径和总超时，校验 `0 < fine_edge <= coarse_edge` |
| `bandbrep/mesh_densification.py` | 拆分纯几何粗加密与场引导细加密；共享剖分函数接收本轮已建立的边索引，避免对同一网格重复排序；两阶段只标记超长边 |
| `bandbrep/reconstruct.py` | 保留 `input_mesh`，依次执行 `coarse_refinement`、`fine_refinement` 阶段；mesh oracle 与模型身份始终绑定原始网格 |
| `bandbrep/bands.py` | 接收经过坐标／顺序核验的最终中心字段，沿用原有分割与顶点域算法 |
| `bandbrep/cache.py` 与报告 | 新配置、实现与两阶段产物纳入缓存身份；旧单级缓存不续用 |
| `benchmarks/run_mesh_input_experiment.py`、分析脚本 | 复用通用框架，冻结新配置和独立输出，分别记录两阶段耗时、面数和查询量 |
| README 与算法文档 | 已同步新入口、阶段表、配置和产物说明 |

粗阶段输出到原始面的映射；细阶段映射需要组合成 `original_parent = coarse_parent[fine_parent]`。本次仅在原三角形内部剖分，保持单一原父面契约，不引入跨父面重三角化。

阶段产物为 `coarse_mesh.npz`、最终 `working_mesh.npz`（含 `parent_triangles`）、`center_fields.npz`（记录坐标、值与 provider 身份）、`coarse_refinement_progress.json` 和 `fine_refinement_progress.json`。`run.json` 分别记录两阶段报告与累计时间，外部 watchdog 沿用每例进程树总超时。

## 4. 验证与重新实验

1. 几何测试：闭合共享边的各切分模式、方向、非零面积、壳数、欧拉特征及面积／有向体积保持不变。
2. 阈值测试：粗阶段不调用任何场；全局达 0.02；细阶段不标记已达 0.005 的短边，边界过渡保持一致，最终近场达标。
3. 契约测试：模型 condition 和 mesh oracle 仍绑定原始网格；原父面映射正确；中心字段复用与直接查询结果一致；超时和缓存身份正确。
4. 运行现有立方体、圆柱、腔体和贯通孔重建回归，验证面、图与 STEP。
5. 先以 `00000168`、`00000602`、`00000688` 检查极粗、已达标过但后续失败、瘦长三类输入；通过后在独立冻结批次运行原来的 20 dev，10 check 保持不运行。

首次验证固定粗目标 0.02，不同时叠加更多参数组。统计粗／细面数和耗时、E/V 查询量、最终近场最长边、闭合与几何不变性、面／图／STEP，以及超时和失败原因。与保留的旧 MC、原生四轮历史结果配对；被清理的中止批次不作为完整成绩基线。

粗阶段会增加远场基础面数，也不能单独消除所有瘦长形状。验收需同时看总耗时、细分面数和拓扑结果；不预先承诺恢复到 150 万面以内。所有阶段共同使用原来的总时间预算。
