# 面向扫描点云与生成式 Mesh 的退化数据构造与抗噪训练方案

本文档承接 [Challenge.md](Challenge.md)、[Pipeline.md](Pipeline.md)、[VectorFieldTarget.md](VectorFieldTarget.md) 与 [Dataset.md](Dataset.md)，系统阐述针对**真实扫描点云/重建网格**与**生成式 Mesh（SAM 3D / Hunyuan3D / Trellis）**的真实退化数据构造方式、冻结 Hunyuan3D 几何先验的保留论证、以及 8D 联合场 VAE 与 `FieldDiT` 的分阶段抗噪训练策略。

---

## 1. 为什么不能只用简单高斯噪声

真实扫描数据与生成式 Mesh 的误差分布与独立同分布高斯噪声存在本质差异：

| 输入域 | 真实误差形态 | 简单逐点高斯噪声的缺陷 |
|---|---|---|
| **生成式 Mesh**（SAM 3D / Hunyuan3D / Trellis） | **空间强相关、低中频系统性偏差**：MC 锐边削圆内缩、细槽变浅、平面轻微鼓包波浪、圆柱微椭圆、法向缓变偏斜、导出强简化（如 `simplify=0.95`） | 无法模拟大面积平滑偏移、锐边圆钝内缩与空间相关法向失真 |
| **真实扫描点云 / 重建网格** | **视角相关误差**：沿视线深度噪声、掠射角丢点（恰在锐边/倒角处形成空洞）、遮挡缺失、多视角配准微小漂移、Poisson 重建圆角与补洞鼓包 | 无法模拟边缘空洞、非均匀密度、配准错位与 Poisson 圆角 |

## 2. 真实退化配对数据的四层构造管线

**核心工程利好**：所有退化仅作用于**输入表面 $\tilde{S}$**（编码器输入与 M4 `g_patch` 输入）；**v5 下游 3D 解码查询池（`near_surface / edge_neighborhood / vertex_neighborhood / edge_zero / vertex_zero` 的精确 CAD 8D 真值）100% 复用，无需重算**。只要输入表面偏移在 `band_max = 0.04` 以内，真实 CAD 边与顶点均稳稳落在近表面三维带中。

### 2.1 面向生成式 Mesh 的退化构造
1. **A 档：同源 3D VAE 重构退化（最高保真、全自动、零配准误差）**
   - 将干净 CAD 网格送入**冻结的 Hunyuan3D 2.1 ShapeVAE**：`encode → 潜变量加轻度高斯扰动 σ ∈ [0, 0.15] → decode → Marching Cubes (96³ / 128³ / 192³)`。
   - **优势**：原汁原味复刻生成式 3D 模型（潜空间解码 + 等值面提取）的全部特征误差——锐边削圆、薄壁微缩、细特征平滑、局部波浪——同时与原干净 STEP 保持 100% 严格空间对齐。
2. **B 档：解析/几何级生成式退化（极低算力、适合大规模离线/在线混合）**
   - **多分辨率体素 SDF + MC 重建**：在 $48^3 \sim 128^3$ 体素网格（加随机半体素偏移）上重提 MC 网格，低成本模拟锐边削圆内缩；
   - **Taubin / Laplacian 迭代平滑（1–5 轮）+ 3D 低频平滑位移场**（如 3D Perlin / RBF 场，空间波长 `0.2 ~ 0.6`，幅值 `0.002 ~ 0.012`）：复刻平面微弯、圆柱微畸变与空间相关法向偏斜；
   - **QEM 网格简化（50%–95%）+ 异质 Remeshing**：复刻显示用 GLB 简化与非 CAD 三角剖分。
3. **C 档：小规模真生成模型闭环（用于真实域评测与末端微调）**
   - 对 1k–3k 个干净 CAD 渲染单/多视图，实跑 SAM 3D / Hunyuan3D / Trellis 得到生成网格，经 Sim(3) + ICP 对齐回原 CAD 并过滤严重幻觉样本（如 Chamfer > `0.02`），作为真实域 OOD 评测集与域适配微调集。

### 2.2 面向扫描点云 / 扫描网格的退化构造
1. **虚拟多视角深度扫描（Ray-Casting / Z-Buffer，类似 CC3D）**
   - 从随机 4–12 个相机视角对干净 CAD 光线投射，叠加**沿视线深度噪声**、**掠射角丢点**（$|\mathbf{n} \cdot \mathbf{v}| < \cos 75^\circ$ 丢弃，天然制造扫描锐边空洞）与微小视角配准刚体抖动；
   - 面向扫描网格输入时，再过一遍 **Screened Poisson 表面重建（`depth = 7~9`）**，复现扫描-重建网格特有的圆角与局部补洞鼓包。
2. **公开数据补充**
   - 结合 CC3D（50k 虚拟工业扫描配对）做跨分布泛化验证。

### 2.3 推荐训练混合配比
- **30% 干净 CAD** + **40% 生成式退化（同源 VAE 重构 / MC / 平滑+低频形变 / 简化）** + **25% 扫描退化（多视角扫描 + Poisson / 遮挡）** + **5% 轻度高频坐标/法向微扰**。

## 3. 架构决策：保留冻结 Hunyuan3D 几何 VAE 的必要性

在引入退化数据后，**强烈建议保留冻结的 Hunyuan3D 2.1 几何 VAE（`geo_encoder` + `geo_latent_decoder`），不要去掉该结构**：

1. **天然具备强抗噪全局形状概括能力**：Hunyuan3D 2.1 是在海量非理想 3D 资产上预训练的 4,096 token Transformer VAE。退化网格中 85%–95% 的大面观测位置与宏观拓扑仍有效，冻结几何主干既能复用百万级通用 3D 抗噪先验，又可防止在小规模 CAD 退化数据上遗忘先验。
2. **保住 Flow 与 VAE 潜空间的严格锚点对齐**：`FieldDiT` 依赖 `z_g` 与 `z_f` 在同一组 4,096 `anchor_xyz` 上逐 token 对齐（+ 3D RoPE）；去掉几何 VAE 会同时丢失预训练先验与空间锚定优势。
3. **消除解码器与 M4 的分布偏移（OOD）**：若 VAE 只在干净网格上训练而仅对 Flow 加噪，推理时退化网格 $\tilde{S}$ 采出的锚点 $\tilde{A}$、退化 `memory_g` 和圆钝法向的 M4 `g_patch` 会直接触发解码器 OOD。冻结 `geo_encoder / geo_latent_decoder`、在混合退化输入上微调可训练的 **`geo_query_decoder (GQ)`、`field_latent_decoder` 与 `M4`**，可让解码器学会在平滑大面参考 `memory_g / g_patch`，在圆钝锐边处依靠 `memory_f` 跳出圆角还原空中真实锐边。
4. **与“近表面 3D 窄带 + 8D 向量场”高度协同**：即使输入表面 $\tilde{S}$ 被削圆内缩 `0.008 ~ 0.015`，推理时对退化表面点执行一步拉回 $\tilde{\mathbf{x}} + \hat{\mathbf{u}}_E(\tilde{\mathbf{x}})$ 即可直接跨出圆钝表面、精准还原空中真实锐边与尖角。

## 4. 退化输入对 UDF / 向量学习的影响与训练策略

### 4.1 物理一致性与后验信息完备性
1. **严格按退化点真实坐标标注（禁止错位贴标）**
   - 解码器 3D 查询池（v5 盘上 5 池）定义在干净 CAD 空间，**直接复用**；
   - 编码器输入点 $\tilde{\mathbf{x}}_i \in \tilde{S}$ 的监督标签必须用 `FeatureUDFOracle` 在 $\tilde{\mathbf{x}}_i$ 的**实际 3D 坐标**上精确求解，保证坐标与标签严格物理自洽。
2. **解决圆钝表面缺乏零点的后验瓶颈**
   - 当输入网格被削圆内缩 `0.01` 时，$\tilde{S}$ 上几乎没有 `dE ≈ 0 / dV ≈ 0` 的点，若 `encode_field` 仅输入 2D 标量 `[dE(\tilde{x}), dV(\tilde{x})]`，后验 $z_f$ 的零集定位上限可能受限。
   - **推荐优化**：在训练期 `encode_field` 输入中，将退化表面点 $\tilde{\mathbf{x}}_i$ 处的精确 6D 位移 `[uE(\tilde{x}_i), uV(\tilde{x}_i)]` 一并拼入（8D 后验输入）。这样即使 $\tilde{\mathbf{x}}_i$ 偏离真实锐边 `0.012`，$\tilde{\mathbf{x}}_i + \mathbf{u}_E(\tilde{\mathbf{x}}_i)$ 仍以解析精度将空中真实锐边坐标写入 `z_f`；推理期 `FieldDiT` 仅以 $\tilde{z}_g$ 预测 `z_f`，**完全无信息泄露**。

### 4.2 三阶段课程训练路线
1. **Stage 1（干净数据打穿上限）**：在 100% 干净 v5 数据上训练 8D `EdgeVertexShapeVAE`，先将零集与中场单步拉回精度压至 `< 0.001`。
2. **Stage 2（混合退化微调 VAE）**：冻结 `geo_encoder / geo_latent_decoder`，以 Stage 1 权重热启动，在「30% 干净 + 70% 真实退化」混合数据上微调 `encode_field + field_latent_decoder + GQ + M4`，验证干净输入不掉点且退化输入能跨面还原锐边。
3. **Stage 3（同分布训练 `FieldDiT`）**：用 Stage 2 的混合退化数据（同一干净 CAD 可配多个退化变体 $\tilde{S}^{(1)}, \tilde{S}^{(2)}, \dots$）缓存 `(\tilde{z}_g, z_f, \tilde{A})` 训练条件 Flow。

## 5. 能力边界（与下游全局正则化分工）

- **本方案射程内**：偏移量在 `0.02 ~ 0.03` 以内（落在 `band_max = 0.04` 射程内）的 MC 削圆、扫描噪声、轻度低频形变、网格简化与局部小缺失，由“退化微调 8D VAE/Flow + 近表面 3D 带跨面拉回”直接解决。
- **交由下游后处理兜底**：SAM 3D 单图重建产生的宏观结构性幻觉、背面大面积错误补全或整体比例系统性畸变（偏移 `> 0.05`），超出局部隐式场射程，应由 [Challenge.md](Challenge.md) 所述的**全局几何约束正则化（平行/垂直/共轴/同半径/对称优化）与 OCC 拓扑校验闭环**协同处理。
