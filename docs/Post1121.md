## 1. 输入契约与设计前提

记输入条件网格为 $C$，配准后的目标 CAD 为 $B^*$，目标非 seam 有限边与必要顶点集合为 $E^*, V^*$。**上游模型不单独生成 SDF**，推理时直接在距输入网格表面 `band_width = 0.02` 的三维近表面空间内连续查询标量距离场：

$$
d_E(x) = \operatorname{dist}(x, E^*), \qquad d_V(x) = \operatorname{dist}(x, V^*).
$$

| 数据 | 作用 |
|---|---|
| 归一化闭合三角网格 $C$ | 提供空间近表面查询带（`|s_C| ≤ 0.02`）、拓扑切分载体与曲面拟合内点观测；允许存在相对真实 CAD 的局部偏移、噪声与棱边圆化 |
| 连续 E/V 查询 $\hat d_E, \hat d_V$ | 在固定 latent 下按需查询，用于三维空间内独立恢复顶点、边与拓扑连接（不依赖网格顶点/边精确贴合 B-rep） |
| 容差体系解耦 | `scan_offset_tolerance = 0.02`（用于曲线嵌入与核心内点验收）与 `boundary_tolerance = 0.001`、`cad_tolerance = 0.002`（用于共享边、pcurve 与 STEP 装配）严格分离 |
| 输出 | 共享顶点与三维参数边、面域与有向边环、通过 OCC `BRepCheck` 与 STEP 读回校验的 `reconstruction.step`，以及各阶段诊断与可选 MC 薄壳 OBJ |

* **首版偏移假设与带边约束**：对可观测配准区域，假定目标表面到输入网格的局部偏差不超过 `0.02`；在默认带宽 $w = 0.02$、管壳半径 $r = 0.005$、细格步长 $h = 0.003$ 下，完整管壳与一层外格均落于带内的保守条件为 $\delta + r + \sqrt{3}h \le w$（$\delta \lesssim 0.0098$）。超界角点标记为 `unknown`，绝不封口或补零。
* **退化特征策略**：对于超短边与极近平行边（尺度低于体素/预测场分辨率极限），默认启用受控合并（`allow_feature_collapse = true`，`collapse_tolerance = 0.005`），优先保证闭合流形 B-rep 的重建成功率。

## 2. 相比最原始方法的整体优化总结

已清理过时的 `sections` 管壳截面中心线、`mc_udf_refine` 与 `edge_geometry.py` 等旧逻辑。当前实现相比最初的边优先基准（`v1`）的核心改进如下：

| 模块 | 最原始方法 | 当前优化后方法 | 核心收益 |
|---|---|---|---|
| **1. `scout` 近表面分层采样** | `0.03 → 0.015 → 0.003`（末级 5 倍展开，每块 216 角点，单模型约 2.81M 细查点） | **全程二分 `0.024 → 0.012 → 0.006 → 0.003`**（末级 2 倍展开），细查前全局去重；新增稀疏局部管道查询 `sample_local_tube()` | 唯一查询点数降 **~2.9×**（2.81M → 0.97M），显著降低精确场与未来 GPU 解码开销 |
| **2. V 球壳顶点恢复** | 单尺度 `V=0.005` MC 拟合，粘连球壳直接报 `vertex_shell_ambiguous` 丢弃 | 先用**缓存 V 局部极小值**拆分，再按需局部 `h/2` 细化；仍不可分时按 `allow_feature_collapse` **合并为超级顶点**并放大其切球覆盖粘连簇 | 消除近邻顶点漏检与由此引发的大面积球外骨架分叉 |
| **3. 骨架细化与线框拟合** | 纯欧氏边界深度删减；切球固定上限 `2h=0.006`；遇 `deg>2` 整片丢弃；`thinning` 漏调短边恢复；`fit_geometry` 用严格单点 `max≤0.001` 验收 | 删减序融合 `-E` 谷值；新增毛刺剪枝、**锐角并管自适应扩切球**、**极窄平行气泡压扁**、稀疏局部 `(h/2, r/2)` 细化与表面距离门禁；补齐切球内短边恢复；支持超短边收缩与极近重边合并；`refine_voxel_centers` 输出 `refined_mask` 按精修置信度鲁棒拟合 | 消除锐角并管丢边、单点未精修误杀标准圆及跨空错连，大幅提升复杂模型线框完整性 |
| **4. 曲线嵌入与网格切分** | 逐点 `closest(q)` + `EPS=2e-9` 极紧吸附，沿网格折痕高频触发自身回退重叠；硬卡 `feature_sdf_tolerance=0.004` | 合理局部吸附尺度 + **往返尖刺化简 `_simplify_segments()`**；路由加入薄壁法向翻转惩罚与已占用内部节点物理避让；解耦 `scan_offset_tolerance=0.02`；不同边重叠时支持受控合并重试 | 自身回退重叠（`edge==other_edge`）彻底清零，面向偏移扫描网格更稳健 |
| **5. 曲面拟合与自由面分片** | 全区域均匀 L2 拟合；自由面仅单 PCA 平面投影 + `1e-7` 刚性边界约束；Patch 回退仅支持单刀切 2 块（无法切环面） | **边界腐蚀核心采样** + `soft_l1` 鲁棒解析/旋转面拟合；自由面支持 **LSCM 内蕴网格参数化 + 薄板平滑能量样条 + 有序 UV 连续追踪**；支持双连通面**跨环成对双切**；对合并边执行**两侧解析面精确求交重定位（`GeomAPI_IntSS`）**；排除 `cone`/`sphere` 解析极点伪折叠 | 解决大曲率/双环自由面拟合失败，让合并后的边/顶点仍满足 CAD 装配容差 |
| **6. OCC 周期面与实体装配** | 周期带仅支持同母线 `cylinder/cone`，异母线或 `torus` 退回 `FixMissingSeam` 替换共享边；收尾重复强跑 `breplib.SameParameter` 导致 `sphere`/`torus` 失效 | 全周期面（含 `torus`/`sphere`）显式 seam，支持**异母线 UV 线性螺旋 seam** 零切分保持共享边；用 `ShapeFix_Edge().FixSameParameter` 兜底修复 `SameParameter` 标志并避免收尾覆盖 | 消除周期面共享边替换与 `BRepCheck_InvalidSameParameterFlag` / `cad_solid_invalid` |

## 3. 详细重建流程

完整流水线按 **`scout → wireframe → split_mesh (或 fast_faces) → surfaces → cad`** 五阶段串联，入口为 [edge_first.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/edge_first.py)，支持 `--stop-after scout|wireframe|split_mesh|solid` 分段调试。

### 阶段 1：`scout` — 近表面全程二分稀疏查询

实现：[edge_first_grid.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/edge_first_grid.py)

1. **候选粗块生成**：对输入网格按 `3 × H` 粗加密后光栅化包围盒，在 `|s_C| ≤ band_width + R` 范围内筛选初始 `H = 0.024` 块，避免对全域 `[-1, 1]^3` 建稠密体素缓冲。
2. **全程二分筛选（`0.024 → 0.012 → 0.006 → 0.003`）**：
   * 利用距离场的 1-Lipschitz 性质，对边长 $s$、半对角线 $R = \frac{\sqrt{3}}{2}s$ 的块中心 $c$，当 E 或 V 任一有效通道满足 $d(c) \le r + \text{margin} + R$ 时保留；
   * 块中心落在带外/未知区时，补查 8 个块角点及最近表面探针，保证保守不漏选；
   * 使用半细格整数键（64-bit packed key）跨层级复用已查询缓存。
3. **末级去重细查**：对保留的 `0.006` 块以 `factor = 2`（每块仅 `3³ = 27` 个角点）生成细格坐标，全局去重后按 `query_batch_size` 分批调用连续 E/V 查询，输出 `scout.npz`。
4. **局部按需查询接口**：
   * `sample_local_box()`：用于粘连 V 球壳的局部 `h/2` 细化盒；
   * `sample_local_tube()`：仅围绕未解析骨架组件及关联顶点生成稀疏局部 `h/2` 管道体素，避免 3D 对角组件的外接盒体素爆炸。

### 阶段 2：`wireframe` — V 球壳定位、3D 保拓扑细化与参数曲线拟合

实现：[edge_first_mc.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/edge_first_mc.py)、[shell_geometry.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/shell_geometry.py)、[voxel_skeleton.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/voxel_skeleton.py)、[skeleton_paths.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/skeleton_paths.py)、[edge_first_graph.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/edge_first_graph.py)

1. **V 球壳顶点恢复（`shell_vertices`）**：
   * 从缓存 V 细格提取 `V = 0.005` 局部 Marching Cubes 球壳（仅使用八角均有效的单元，不封口），输出 `vertex_shell.npz`；
   * 对每个连通球壳用 `soft_l1` 拟合自由半径球心，再用邻域缓存 V 做“位置 + 常偏置”联合精修；
   * 若球壳因近邻顶点粘连被判为 `vertex_shell_ambiguous`：先在缓存 V 网格上提取 26-邻域局部极小值并用 Voronoi 分区独立精修；仍粘连则调用 `sample_local_box` 在 `h/2` 上重提；若开启 `allow_feature_collapse` 且仍不可分，直接合并为**超级顶点**并放大其切球半径覆盖整个簇。
2. **3D 保拓扑体素细化（`thin_volume`）**：
   * 取有效前景 `E ≤ shell_radius`，保护切球内的顶点锚点与未知带边交界体素；
   * 按混合优先级 `depth - 0.35 * (E / h)`（综合边界距离与 E 谷值）由外向内删除 26-前景 / 6-背景单连通简单点，输出 `edge_skeleton.npz`。
3. **切球截断、分叉消歧与短边恢复（`trace_paths` + `_resolve_local_junctions`）**：
   * **锐角自适应扩切球**：当 `deg > 2` 分叉落在顶点外侧且处于锐角并管区内（`≤ min(0.45 * gap, 3.2 * r)`）时，局部放大该顶点切球半径以干净切过分叉；
   * **去毛刺与窄气泡压扁**：剪除无端口锚的短毛刺；开启 `allow_feature_collapse` 时，将两个 `deg > 2` 节点之间横向间距 `≤ max(1.5 * collapse_tolerance, 2r)` 的平行双链气泡压扁为单链；
   * **短边恢复**：先从切断前的原始骨架连通图做受限 BFS 恢复完全被切球吞没的短边（`recover_cut_ball_short_paths`），再以缓存 E 离轴观测补充复核（`add_short_paths`）；
   * **稀疏局部管道重提与分叉点提升**：对剩余 `skeleton_junction_unresolved`，在稀疏局部管道内按 `(h/2, r/2)` 最多细化 `local_refine_levels` 层，通过**表面距离门禁**（`_path_near_surface`）过滤跨空错连并支持部分采纳；若细化后仍残留 `deg > 2` 分叉且开启 `allow_feature_collapse`，通过 `_promote_unresolved_junctions()` 将近邻分叉簇并入已有顶点切球或提升为**合成顶点**，再按 `deg != 2` 拆链输出并打标 `collapsed = True`，杜绝整片丢弃骨架；
   * **受控特征合并**：开启 `allow_feature_collapse` 时，收缩长度 `≤ collapse_tolerance` 的连通短边，合并同端点极近平行重边，并标记 `collapsed_edges`。
4. **亚体素中心精修与参数边拟合（`refine_voxel_centers` + `fit_geometry`）**：
   * 在收紧的横向法平面邻域（`min(2.2h, r+h)`，`E ≤ r+h`）内对缓存 $E^2$ 做加权迭代二次拟合，输出每点的精修置信掩码 `refined_mask`；
   * 固定共享端点依次尝试直线、圆/固定端点圆弧、分段 C1 三次 Bézier；按 `refined_mask` 加权拟合，已精修点严格满足 `curve_tolerance (0.001)`，未精修原始格点放宽至 `max(tol, 0.75h)` 避免单点体素量化误杀标准圆；对 `bezier_spline` 增加**拟合后表面贴合复核（`_curve_near_surface`）**，发生空白段过冲时自动触发弦长补点（`_densify_chord_gaps`）保形重拟。输出 `wireframe.json`、`curves.json`。

### 阶段 3：`split_mesh`（及可选 `fast_faces`）— 线框嵌入与面域划分

实现：[fast_faces.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/fast_faces.py)、[edge_first_embedding.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/edge_first_embedding.py)、[boundary_cycles.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/boundary_cycles.py)

1. **可选平面快速路径（`fast_faces`）**：全平面模型可先尝试把线框粗投影到原网格边并用 RANSAC 拟合平面，若通过边界与 STEP 验收直接写出 `face_regions.npz`；否则走精确切面路径。
2. **精确曲线嵌入（`SurfaceCut`）**：
   * 仅在拓扑副本上切分三角形，三维参数线框几何保持不变；
   * `locate()` / `edge_node()` 采用局部自适应吸附尺度（`min(1e-5, 0.05 * edge_len)`），并对非端点避让其他边已占用的原网格顶点与 Steiner 内部节点 `claimed_interior`（沿边/向三角形重心做物理偏移防止哈希冲突）；同时在共享顶点 `1.5 × spacing` 邻域内跳过过密采样点，避免锐角共顶点边挤入同一网格边；
   * `route()` 在曲线走廊内做带薄壁法向翻转惩罚的局部 Dijkstra 路由；整条曲线路由完毕后经 `_simplify_segments()` 消除往返尖刺 `u → v → u`；
   * 对受影响三角形做 2D `polygonize` + 约束 Delaunay 剖分，未受影响三角形原样复用；
   * 若遇不同边 `curve_embedding_overlap` 且开启 `allow_feature_collapse`，自动舍弃较短重叠边、将保留边标记为 `collapsed` 并重试切面。
3. **面域标记与有向边环**：在切分网格上以屏障边断开三角形邻接求连通分量，校验每条逻辑边两侧面标签唯一且异面，构建每个面的外环与孔环，输出 `split_mesh.npz` 与 `logical_graph.json`。

### 阶段 4：`surfaces` — 鲁棒曲面拟合、自由面分片与合并边求交重定位

实现：[surface_fitting.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/surface_fitting.py)、[face_patches.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/face_patches.py)

1. **边界腐蚀核心采样与解析/旋转面拟合**：
   * 按面积加权采样面内点，并通过 `_core_samples()` 剔除紧贴边界的过渡带（规避扫描件棱边圆化失真）；
   * 依次以 `soft_l1` 鲁棒优化拟合平面、球面、圆柱及旋转面（圆柱/圆锥/圆环），筛选时使用核心区 `p90 ≤ 2 * surface_tolerance` 与 `max ≤ scan_offset_tolerance`（解耦扫描偏移与 CAD 容差）。
2. **自由面 LSCM 参数化与平滑样条（`fit_general_spline`）**：
   * 当面域法向跨度较大（`min_dot < 0.25`）或 PCA 投影失败时，在面域三角网格上求解 **LSCM 内蕴共形参数化**；
   * 用高权边界最小二乘（`w_bnd = 35`）+ 控制网二阶薄板弯曲平滑能量求解张量 B-spline，并在 `FacePatch.uv(..., ordered=True)` 中对有序曲线做连续性追踪，消除 pcurve 中点跳变。
3. **两阶段合并边求交重定位（`_refit_collapsed_edges`）**：
   * 对含 `collapsed_edges` 的面先放宽合并边初筛容差以拟出准确主曲面；
   * 随后对两侧均为解析面的 `collapsed` 边调用 OCC `GeomAPI_IntSS` 求**精确解析交线**替换粗合并中线并更新端点，再统一执行边界误差与 Jacobian 校验（排除 `cone` 尖顶与 `sphere` 极点处的自然奇异点）。
4. **双连通与单连通 Patch 回退（`fit_with_patch_fallback`）**：
   * 单域自由面拟合失败时，若面具有 ≥2 个边界环（双连通/环形面），优先提出**成对不相交的跨环内部切线**将环面拆为 2 个单连通盘；单连通面则提出单条内部切线，共享内部三维接缝并记录 `patch_to_logical_face` 映射。输出 `face_patches.json`。

### 阶段 5：`cad` — OCC 共享拓扑装配、显式周期 Seam 与 STEP 读回

实现：[occ_assembly.py](file:///opt/data/private/yihengxu/DualBrep/band_brep_reconstruction/bandbrep/occ_assembly.py)

1. **共享顶点/边与 pcurve**：每个逻辑顶点与逻辑边仅构造一次 `TopoDS_Vertex` / `TopoDS_Edge`，逐面附着 pcurve 并校验中点误差。
2. **全周期面显式 Seam**：
   * 无全缠绕周期面旋转参数框将 $u$ 切口置于角度空隙（免 seam）；
   * 同轴双闭环与球冠直接构造显式母线/经线 seam；
   * 双缠绕环（支持 `cylinder`、`cone`、`torus`、`sphere`，含闭环 + 多边环混合及**上下环顶点位于不同母线**的情况）构造连接已有顶点的等 $u$ 或 **UV 线性（螺旋/斜线）显式 seam**，零切分保持共享边身份。
3. **`SameParameter` 保护与实体读回验收**：
   * 单面与实体装配均在 `breplib.SameParameter` 后检查标志，必要时调用 `ShapeFix_Edge().FixSameParameter(..., cfg.cad_tolerance)` 兜底，避免重复强跑覆盖有效标志；
   * 执行 `OrientClosedSolid`、双面反向使用校验、最大容差校验、`BRepCheck_Analyzer`、OCC 三角化、STEP 导出读回、体积与采样曲线几何一致性校验，通过后原子落盘 `reconstruction.step`。

## 6. 设计原理、失败诊断、校正选项与消融协议（原 `MCShellCenterline.md` 合并）

### 6.1 为什么改用管壳/体素几何替代壳点梯度投影
* 预测场总体 MAE 约 `0.002`，在真值 `< 0.001` 的近零区仍约 `0.002`，直接以小步长差分梯度反复把壳点推向零谷易受偏差和局部波动影响；历史批次中 13 个完成样本的 MC 出壳中位仅 `2.31 s`，而壳点逐点投影高达 `363.84 s`。
* 使用 `E = 0.005` 等值管壳/前景（默认 `centerline_method=thinning` 三维保拓扑细化，历史上曾以 `sections` 截面圆心推进作对照）从更大空间收集对称性信息，可将逐点投影替换为纯几何运算，并把后续拟合和验收中的新增 E 查询纳入消融。

### 6.2 按管壳、中心线与端点关联定位失败
| 失败位置 | 判据与原因 | 处理与记录 |
|---|---|---|
| 查询与 MC 出壳 | 管壳漏提取、被有效带截断、与邻管融合或整体偏心 | 八角均有效才出壳；用缓存粗细查询区分无等值交叉、角值未知与疑似融合；缩小等值半径与细化格距分别验证 |
| 骨架 / 中心线提取 | 可信壳段未被覆盖、截面角覆盖不足、跨环或轨迹不连续 | 记录未解释壳段，区分无壳、证据不足与漏提取；证据不足则标未解析 |
| 球面切断与端点关联 | 路径与多球相交、顶点球重叠或并管无法拆开 | 对线段 $a + t(b - a)$ 解 $\|a + t(b - a) - v\|^2 = R^2$（$t \in [0, 1]$）区分出入口与切向；结合壳面可达性与竞争假设复核 |
| 参数边拟合与验收 | 未覆盖可信中心线、偏离支持区或端点/闭合约束失败 | 以几何覆盖、连续性与共享端点验收，不因中心线上预测 E 仍有 `0.002` 单独拒绝 |

### 6.3 UDF 校正选项与部分线框容错
| 模式 | MC / 细化后的场查询 | 拟合与验收 |
|---|---|---|
| `off`（默认） | 复用已有格点 E/V 和壳几何，中心线、拟合及覆盖验收不新增 UDF 查询或差分 | 以骨架中心、壳支撑、缓存观测、连续性和共享端点验收 |
| `sparse`（可选） | 仅对少量低置信中心点在法截面内补查标量 E（合批去重），限制偏移 | 仅接受改善残差且不改变端点归属的修正 |
| `legacy`（历史对照） | 壳顶点逐点向低谷投影 | 仅用于比较查询成本与恢复差异 |

* 实验配置设 `"allow_partial_wireframe": true` 时：支撑点到有序中心线最大偏差超 `3 × curve_tolerance` 记录 `curve_support_branching` 告警并保留中心线供拟合；只要得到可用参数边即继续尝试分面与装配，并在 `run.json` 记录 `continued_with_warnings`（STEP 几何与拓扑验收仍照常严格执行）。

### 6.4 粗投影快速分面、按需切面与自由面 Patch 划分原则
* **粗投影快速路径（`fast_faces`）**：先将共享顶点映射到 `band_width` 内原网格顶点，在原网格边图中沿曲线走廊寻最短连续路径作为三角形邻接屏障划分面域，远离边界采点做 RANSAC 平面拟合；原网格过粗、近邻边重合或平面验收失败时回退精确切面。
* **按需局部切面（`SurfaceCut`）**：仅作用于拓扑副本（三维参数线框保持原值）；沿原网格边的路径直接作屏障不重剖分，穿过三角形时建局部子区域并做约束 Delaunay 剖分，未受影响三角形原样复用；逐段核对左右面一致性与孔环。
* **自由面 Patch 划分原则**：先查外边界自交、UV 翻折与固定边界残差，局部误差优先加样条节点；确认单域参数化严重挤压或绕转后，从高畸变/高残差处选短候选切线先拆 2 块（双连通环面成对跨环双切），两块共享内部三维接缝并校验位置与 pcurve 一致，记录 `patch_id → logical_face_id` 供按逻辑面评分。

### 6.5 受控消融验证顺序
1. **固定壳换提取器**：同局部 MC 壳对照保拓扑细化、`sections` 与历史逐点投影，测直管/弯管/无顶点闭环/Y 型交汇/短边/并管/带边截断。
2. **接 V 球壳定位与拟合**：验证球壳偏移、半径收缩、小球帽、球壳融合、短边全覆盖及共享端点一致性。
3. **同采样同壳配对消融**：依次在精确 E/V、受控对称/方向偏差与真实预测场上对比 `off`、`sparse`、`legacy`。
4. **分层查询消融**：固定中心线方法，对比 `0.03→0.015→0.003` 与全二分 `0.024→0.012→0.006→0.003` 的召回、唯一查询量、耗时与截断壳数。
5. **固定线框测下游**：对比 `fast_faces` 与 `split_mesh`、单片样条与 Patch 回退的质量与耗时；所有对照分别报告质量指标与各阶段查询/计算成本。
