# 后处理流程设计规范（Post1125：8D 向量拉回 + 无网格切分面环匹配版）

更新：2026-11-26。本文确立 `band_brep_reconstruction` 的现行与目标后处理主线：**8D 联合场中场向量拉回线框 + 3D 线框直接拓扑成环 + 边界先验代理与点云核心团协同匹配 + 未裁剪参数化曲面拟合 + OCC 边界裁剪装配**，彻底摆脱对输入网格三角拓扑与分辨率的依赖，原生兼容网格重采样点云与纯点云输入。

## 0. 总览：全链路架构与核心原则

```text
输入：表面点云 P = {(p_i, n_i)}（若为网格则表面均匀采样，抛弃原三角拓扑）+ 8D 连续场 [dE, dV, uE(3), uV(3)]

scout → wireframe (8D vector_pull + 曲线拟合) → face_cycles (3D 线框定环)
      → point_matching (核心点团投票 × 边界先验代理) → surfaces (未裁剪曲面拟合) → cad (OCC 裁剪装配)
```

### 核心设计原则
1. **预处理与 8D 场绝不沿 seam 切面**：完整圆柱、圆锥、球面在 $360^\circ$ 方位角上无几何特征，沿 seam 切面会向 `E-UDF / uE` 引入严重多义性并向 `V-UDF` 注入伪顶点。数据预处理坚持 `ShapeUpgrade_UnifySameDomain` 合并同域面、不把 seam 加入 E 通道；周期面装配统一由下游 `occ_assembly.py` 显式规划 seam 与极点退化边。
2. **解耦“定面拓扑”与“匹配点云”，彻底取消物理切三角网格**：不再把 3D 线框投影回输入网格做三角形切割与连通分量分面，从而根治低分辨率/削圆网格上的投影重叠（`curve_embedding_overlap`）、窄面切不出三角形（`edge_neighbors_unresolved`）与薄壁跳面问题。
3. **运行与诊断契约**：入口 `reconstruct()` 增量落盘 `run.json` 与最终 `quality.json`，受 `deadline.py` 的 `sample_budget`（默认 `10800s`）与各阶段 `checkpoint()` 约束；外部场契约固定为 **8D 连续场** `[dE, dV, uE(3), uV(3)]`，仅在近表面有效带 `|sdf| ≤ band_width(0.02)` 且 `|x| ≤ 1` 内查询。

## 1. `scout`：近表面稀疏分层采样（`edge_first_grid.py`）

产物 `scout.npz`：`points / keys / values[sdf, dE, dV] / offsets[uE, uV] / valid / blocks`。

1. `candidate_blocks`：对输入表面按包围盒 ±`band_width` 光栅化出 `H=0.024` 候选块，裁剪到 `[-1, 1]^3`，受 `scout_point_budget`（`4e6`）约束。
2. `scout()` 全程二分 `0.024 → 0.012 → 0.006 → 0.003`（`Config.scout_spacings`）：对块中心 `c`、边长 `s`、半对角 $R = \frac{\sqrt{3}}{2}s$，按 1-Lipschitz 保守判据 `dE(c) ≤ scout_margin + R` 或 `dV(c) ≤ scout_margin + R` 保留；块中心无效时补查 8 角点并以最近表面投影点兜底。
3. 所有查询点用 64-bit packed 整数键全局去重缓存（`observe()`），跨层级零重复查场。
4. 末级 `factor=2` 展开成 `fine_spacing=0.003` 细格，批量 `query(..., query_batch_size=65536)` 输出 `values / offsets / valid`（`valid` 逐通道保留，V 失效不影响 E）。

## 2. `wireframe`：8D 中场向量拉回（`vector_wireframe.py`）

`extract_vector_wireframe()` 将几何拉回与拓扑连线解耦，按四步恢复共享顶点与有序边折线：

### 2.1 第一步：E / V 通道并行中场单步拉回
- **V 通道（`_pull_vertex_candidates`）**：
  - 筛选 `valid[:,2] & dV ∈ [0.003, 0.020] & |‖uV‖ − dV| ≤ 0.004`（不足 4 点时下界放宽至 `> 1e-8`）；
  - 拉回 $\mathbf{p}_V = \mathbf{x} + \hat{\mathbf{u}}_V(\mathbf{x})$，过表面贴合门禁 `mesh_d ≤ feature_sdf_limit (0.02)`，按一致性与贴合度赋高斯软权重；
  - 经半径聚类（`vertex_cluster_radius=0.003`、支持数 `≥ 4`）+ **Weiszfeld 加权 L1-median**（4 轮迭代）输出候选顶点中心与展布残差。
- **E 通道（`_pull_edge_points`）**：
  - 筛选 `dE ∈ [0.003, 0.018] & |‖uE‖ − dE| ≤ 0.0035`（无监督剔除中轴假零集与短向量拖尾）；
  - 拉回 $\mathbf{p}_E = \mathbf{x} + \hat{\mathbf{u}}_E(\mathbf{x})$，过表面贴合门禁并赋软权重，同时保留源坐标 `src_xyz` 与源 `dV` 供后续切断（此步不做拓扑连线）。

### 2.2 第二步：E / V 双向互证 + 自适应解析切断球（`_verify_vertices_with_edges`）
对每个候选顶点 $\hat{\mathbf{v}}_i$：
1. **E 点支撑校验**：半径 `max(0.008, 2.5h)` 内 `p_E` 数量 `< 3` → `false_vertex_no_edge_support` 剔除；
2. **标量 `dE` 回查**：批量查询 `dE(v_cand) > max(0.005, 1.5·edge_consistency_tol)` → `false_vertex_high_dE` 剔除；
3. **近重合合并**：`allow_feature_collapse=true` 时合并间距 `≤ collapse_tolerance (0.005)` 的连通候选；
4. **自适应解析切断球**：半径 $r_i = \min(\text{vertex\_cut\_radius}=0.007,\; 0.35\,d_{\min})$，防近距顶点球互相吞并。

### 2.3 第三步：V 主导切断（`_cut_edges_by_vertices`）
剔除满足以下任一条件的 `p_E` 点：源点 `src_xyz` 落入任意切断球 $B(\hat{\mathbf{v}}_i, r_i)$、拉回点 `p_E` 落入任意切断球、或源 `dV ≤ r_i`。彻底绕开交点处 `uE` 多值跳变脏区。

### 2.4 第四步：微体素共识 → 1D 加权 PCA 瘦身 → 切向聚类 → EMST 排序

| 子步 | 实现要点 | 关键阈值 |
|---|---|---|
| 微体素共识 | `_micro_voxel_consensus` 合并拉回点为加权质心并计票，删孤立单票噪点 | `voxel = min(0.001, h/3)` |
| 1D 高斯加权 PCA 瘦身 | `_pca_thin_and_tangents` 求局部切向 `t_i` 与线性度 `(λ1−λ2)/λ1`；**仅横向展布 ∈ `[1e-4, 0.0015]` 时向局部主轴收缩**（极细曲线保曲率，平行边双峰间隙防粘连） | `pca_thin_radius=0.0032`, `iters=3` |
| 切向 + 横向偏移聚类 | `_cluster_tangent_aware` 丢 `linearity < 0.3` 团块噪声；点对须同时满足欧氏距离、切向夹角 ≤ 42° 与横向偏移 `d_perp` 约束 | `edge_link_radius=0.004`, `edge_lateral_tol=0.0018` |
| EMST 直径排序与闭环识别 | 每簇建欧氏最小生成树取最长路径（去环去毛刺）；首尾近距、切向连续且不近顶点者判为无顶点闭环边 | 重采样步长 `min(0.0025, h)` |
| 段级 `dE` 回查 | 每条候选折线取 7 个探针回查 `median(dE) ≤ 0.00525` 与表面距离 `≤ 0.02`，剔除残余中轴伪边 | `edge_consistency_tol=0.0035` |
| 挂接 / 桥接 / 短边兜底 | ① `r_v + max(0.006, 2h)` 内切向对齐挂接顶点；② 间距 `< 0.015`、切向 ≤ 35° 且中点 `dE` 低的未挂接断口自动桥接；③ 间距 `≤ 2.5·0.007 + h` 的近邻顶点回查中段 `dE` 补直线短边；④ 剪除剩余悬空噪段 | 弧长 `≥ 2h` 的未挂接段记入 `unresolved` |

## 3. 曲线拟合：`recover_wireframe` + `fit_geometry`（`edge_first_graph.py`）

- 将挂接后的精确顶点坐标硬约束为曲线首尾端点，按代价递增尝试拟合：
  1. **直线**（由两端点直接解析定义）；
  2. **整圆**（闭环且 `sweep > 5.5 rad` 时强制 $2\pi$）/ **固定端点圆弧**（`fit_fixed_arc`）；
  3. **分段 $C^1$ 三次 Bézier**（`projected_seed`，`spans = 1..max_segments(64)`，必要时弦长加密并做表面贴合复核防过冲）。
- 验收标准：`max ≤ curve_tolerance (0.001)`（或精修点 `p95 ≤ tol & max ≤ 1.5·tol`）。
- 产物：`wireframe.json`、`curves.json`、`edge_support.npz`。

## 4. `face_cycles` 与 `point_matching`：3D 线框直接定环 + 点云协同匹配（新方案）

> 本阶段完全取代旧版依赖网格三角拓扑切割的 `fast_faces` / `split_mesh`（`edge_first_embedding.py`）。若输入为网格，先在表面均匀重采样得到带法向点云 $P = \{(\mathbf{p}_i, \mathbf{n}_i)\}$；若输入为纯点云则直接使用。

### 4.1 3D 线框直接拓扑成环（Wireframe-Driven Face Cycles）
不投影切网格，直接由精确 3D 线框 $G = (V, E)$ 与点云局部外法向枚举全部面环：

1. **有顶点子图 → 流形旋转系统（Rotation System）枚举基本面环**：
   - 对每个顶点 $v \in V$，统计其邻域表面点云（避开紧贴棱边的法向奇异区）的平均外法向 $\bar{\mathbf{n}}_v$（尖角处邻域外法向均值天然指向实体外侧）；
   - 将与 $v$ 相连的所有出边切向量投影到垂直于 $\bar{\mathbf{n}}_v$ 的切平面，按绕 $\bar{\mathbf{n}}_v$ 的**逆时针循环序**排列；
   - 对全部 $2|E|$ 条有向半边执行最小转角追踪：沿半边 $(u \to v)$ 到达 $v$ 后取循环序的下一条出边，闭合即得一个基本面环 $L_k$。天然保证每条无向边被两个面反向共享，宽 `0.001` 的极窄倒角亦 100% 成环、永不重叠。
   - **非凸鞍点兜底**：若某顶点处 $\|\bar{\mathbf{n}}_v\|$ 过小，对相邻出边对张成的角扇区中线向点云 $P$ 投射，贴合表面且无他边阻挡的相邻对判为同面拐角。
2. **无顶点孤立闭环边（完整圆柱/圆锥/球冠/圆孔）**：
   - 将每条孤立闭环边 $C_m$ 拆为方向相反的两条有向环 $C_m^+, C_m^-$，交由 4.2 节核心点团连通性完成三类确定性归属：
     - **单环盖面**（平面圆盘 / 圆锥侧壁 / 球冠）：单侧独立对应一块点云，自成单环面；
     - **双环/多环周期面**（完整圆柱侧壁 / 圆环面）：多条有向环连向同一无阻断核心点团，自动合并为同一面的多个边界环 `cycles[f] = [loop_1, loop_2, ...]`；
     - **内孔环**：某侧连向已有外环面的同一核心点团，自动挂接为该面的内孔环 `inner_loop`。

### 4.2 核心点团投票 × 边界先验代理（Proxy-Guided Point Matching）
将“宽面/自由面”与“极窄面/削圆面”分流协同，兼顾内部高频几何保真度与窄面零失败鲁棒性：

1. **路 1：点云核心团 + 半边侧向投票（主攻宽面、大曲率自由面、周期面与孔洞绑定）**
   - **棱边走廊屏蔽**：在点云 $P$ 中剔除距 3D 线框 $d(\mathbf{p}_i, E) < \delta_{\text{band}}$（默认 `0.004–0.006`）的过渡/削圆点；
   - **屏障感知 kNN 连通分量**：对剩余点云建 kNN 图，仅保留同时满足“欧氏距离近 + 法向夹角小 + 两点连线段距 3D 线框 $> \delta_{\text{band}}/2$（防跨边/跨薄壁穿透）”的边，求连通分量得到干净的**面核心点团** $\{C_m\}$；
   - **半边侧向投票**：每个核心点团的边缘点对最近线框边 $e$ 按叉积符号 $\mathrm{sign}\big((\mathbf{p}_i - \mathbf{p}_e)\cdot(\mathbf{t}_e \times \mathbf{n}_i)\big)$ 投票，判定点团位于边 $e$ 的左/右侧有向半边，从而精确绑定至对应面环 $L_k$（并同步完成孤立闭环的周期合并与内孔归属）。
2. **路 2：无学习边界先验代理（吸收 BrepForge §4.2，专治极窄面、小倒角、削圆区与破洞面）**
   - 对路 1 中未分到核心点团或有效内点数 `< min_core_points (15)` 的面环 $L_k$，直接基于精确 3D 边界环构造**未裁剪先验曲面 $\tilde{S}_k$**：
     - 用 **Newell 算法**累加边界环在坐标平面投影的有符号面积估算稳定法向，将边界点投影到切平面做 PCA 建立正交局部基；
     - 按边界形态生成候选先验：共面环（边界平面残差 `≤ boundary_tolerance`）→ 解析平面；平行双边/圆弧窄带 → 直纹面 / Coons Patch / 解析圆柱圆锥；一般弯曲环 → **局部基低阶二次曲面（Quadratic Surface）**；
   - **几何门控反吸点云**：用 $\tilde{S}_k$ 回到全量点云 $P$ 中筛选同时满足“到 $\tilde{S}_k$ 距离小 + 法向一致 + 投影落在外环 $L_k$ 内部”的补充内点；
   - **零失败兜底**：若吸回足够内点则进入常规联合精修；若因面极窄或输入表面被严重削圆导致无可靠内点，**直接保留由精确 3D 边界环决定的解析/直纹/二次曲面先验作为支撑面**，彻底消除缺内点失败。
3. **可选全局精配（1 轮 EM 点云重分配）**：
   - 所有面环拥有初始支撑面 $\{S_k\}$ 后，按“点到 $S_k$ 距离 + 法向误差 + 投影落入环 $L_k$ 内”对全量点云做一轮重分配与边界约束重拟合，消除过渡带归属歧义。

产物：`logical_graph.json`（含 `cycles` 外环/内孔环）、`face_points.npz`（逐面匹配的核心内点与法向）。

## 5. `surfaces`：未裁剪参数化曲面拟合（`surface_fitting.py`）

与 BrepForge 思路一致，拟合支撑面时**忽略内部孔洞（内环）**，仅保证未裁剪支撑面覆盖外环并精确贴合所有边界曲线与匹配内点；最终裁剪交由 OCC 内核完成。

对每个逻辑面 `f`：
1. **解析面候选（`analytic_candidates`）**：依次尝试平面、球、圆柱、圆锥、圆环（双同心圆边额外插入同轴圆柱候选）；验收条件为匹配内点 `p90 ≤ 2·surface_tolerance (0.006)`、`max ≤ scan_offset_tolerance (0.02)` 且边界偏差 `≤ boundary_tolerance (0.001)`（平面额外要求边界 `≤ 0.25·tol`）。
2. **回转面与自由面**：解析失败则依次尝试 `revolution_candidates()`（`cylinder > cone > torus`）与薄板平滑张量 B-spline 拟合（联合边界曲线采样点与匹配内点）。
3. **窄面/削圆面边界先验直通**：对 Stage 4.2 标记为无可靠内点的极窄面，直接采纳精确 3D 边界环构造的解析/直纹/二次曲面先验。
4. **终检**：校验全边界采样点、匹配内点与 Jacobian 非退化（排除 `cone` 尖顶与 `sphere` 极点邻域）。

产物：`face_patches.json`。

## 6. `cad`：OCC 边界环裁剪、共享装配与 STEP 读回（`occ_assembly.py`）

1. **全局共享拓扑**：每个逻辑顶点/边只构建一次 `TopoDS_Vertex` / `TopoDS_Edge`，逐面投影挂接 `pcurve`（校验中点误差）。
2. **周期面与退化边原生支持**：
   - 同轴环族统一母线参考方向；非全缠绕周期面旋转 UV 框将 `u` 切口放入角度空隙（免 seam）；异母线采用 UV 线性螺旋 seam；`sphere / torus` 构造显式 seam；
   - `cone` 尖顶与 `sphere` 极点分别由 `make_conical_cap()` / `make_spherical_cap()` 自动构造母线 seam 与极点退化边（`Degenerated=True`）；部分旋转面极点方位角跳变自动插入共享顶点退化边。
3. **OCC 内核裁剪与读回终检（`verify_export_and_roundtrip`）**：
   - 由 OCC 按精确外环 + 内孔环裁剪各未裁剪支撑面并缝合实体；
   - 严格校验：体积 `> 0` → 可三角化 → 导出 STEP → 重新读回 → `BRepCheck_Analyzer().IsValid()` → 体积变化 `≤ max(1e-7, 1e-5·V, 面积·boundary_tolerance)` → 面数等于 `graph.face_count` → 曲线采样点到读回边距离 `≤ cad_tolerance (0.002)`。

产物：`reconstruction.step`、`logical_to_cad.json`、`quality.json`。

## 7. 核心参数速查

| 阶段 | 参数 | 默认值 | 作用 |
|---|---|---|---|
| `scout` | `coarse_spacing / fine_spacing (h)` | `0.024 / 0.003` | 二分稀疏格步长调度与重采样基准 |
| `scout` | `band_width / scout_margin` | `0.02 / 0.01` | E/V 有效查询窄带与块筛选保守裕量 |
| `wireframe` | `edge_mid_min / max` | `0.003 / 0.018` | E 通道中场单步拉回筛选带 |
| `wireframe` | `vertex_mid_min / max` | `0.003 / 0.020` | V 通道中场单步拉回筛选带 |
| `wireframe` | `edge_consistency_tol / vertex_consistency_tol` | `0.0035 / 0.004` | `|‖u‖ − d|` 一致性门限（剔除中轴假零集） |
| `wireframe` | `vertex_cluster_radius / vertex_cut_radius` | `0.003 / 0.007` | 顶点聚类半径与解析切断球上限（`min(0.007, 0.35·d_min)`） |
| `wireframe` | `pca_thin_radius / pca_thin_iterations` | `0.0032 / 3` | 1D 高斯加权 PCA 瘦身邻域与迭代轮数 |
| `wireframe` | `edge_link_radius / edge_lateral_tol` | `0.004 / 0.0018` | 切向聚类连边半径与防窄倒角串线横向门限 |
