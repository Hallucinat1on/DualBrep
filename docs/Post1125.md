## 0. 总览：五阶段 + 诊断契约

入口 `reconstruct()`（`bandbrep/edge_first.py:212`）：

```
validate_mesh → MeshFieldProvider → scout → wireframe → (fast_faces | split_mesh) → surfaces → cad
```

- `Run` 类（`edge_first.py:18`）负责每个阶段的 `run.json` 增量落盘（含 `seconds`）、最终 `quality.json`、以及失败时的 `failed_stage / error.code`。
- `--stop-after scout|wireframe|split_mesh|solid` 可分段调试；`split_mesh` 会强制跳过 `fast_faces` 快速路径。
- 整个运行受 `deadline.py` 的 `sample_budget`（默认 10800 s）与各阶段 `checkpoint()` 约束。
- 输入契约（`field_provider.py`）：网格只提供 SDF 与拓扑载体；外部 `udf` 提供 **8D 连续场** `[dE, dV, uE(3), uV(3)]`，`FieldEvaluation.values=[N,2]`（dE,dV）、`offsets=[N,2,3]`（uE,uV）。`MeshFieldProvider.evaluate()` 仅在 `|sdf| ≤ band_width(0.02)` 且 `|x|≤1` 内真正查询 E/V，域外返回哨兵 `EMPTY_DISTANCE` 并置 `valid=False` —— 这条“带内才有 E/V”的规则贯穿后续所有筛选。

## 1. `scout`：近表面稀疏分层采样（`edge_first_grid.py`）

产物 `scout.npz`：`points / keys / values[sdf,dE,dV] / offsets[uE,uV] / valid / blocks`。

1. `candidate_blocks`：先 `coarse_refine_surface(mesh, 3*0.024)` 得到粗化代理，再按三角形包围盒 ±`band_width` 光栅化出 `H=0.024` 候选块，裁剪到 `[-1,1]^3`，并受 `scout_point_budget`（4e6）约束。
2. `scout()` 全程二分 `0.024 → 0.012 → 0.006 → 0.003`（`Config.scout_spacings`）：对块中心 `c`、边长 `s`、半对角 `R=√3/2·s`，用 1-Lipschitz 保守判据 `d_E(c) ≤ margin + R` 或 `d_V(c) ≤ margin + R`（`margin = scout_margin = 0.01`）保留；块中心落在未知区（E/V 无效）时补查 8 个角点，再把最近表面投影点作为探针兜底（`surface_probes` 计数）。
3. 所有查询点用 64-bit packed 整数键做全局去重缓存（`observe()`），因此跨层级不会重复查场。
4. 末级 `factor=2` 展开成细格（步长 `fine_spacing=0.003`），再次去重后批量 `query(provider, ..., query_batch_size=65536)`，输出 `values/offsets/valid`（`valid = result.valid & ~saturated & isfinite`，**逐通道保留**，V 失效不影响 E）。

> 与文档的差异：`docs/Post1121.md` 阶段 1 里提到的 `sample_local_box()` / `sample_local_tube()` 已随旧的 MC 前端一起移除，现在 `scout` 只做纯二分采样。

## 2. `wireframe`：8D 中场向量拉回（核心，`vector_wireframe.py`）

`extract_vector_wireframe()`（`:617`）把 `VectorFieldTarget.md` §4.1 的四步串起来；中间统计写入 `wireframe.json` 的 `skeleton` 字段。

### 2.1 第一步：E / V 通道并行中场单步拉回

**V 通道**（`_pull_vertex_candidates`, `:45`）
- 掩码：`valid[:,2] & dV ∈ [0.003, 0.020] & |‖uV‖−dV| ≤ 0.004`；若命中 < 4 点则退化为 `dV ∈ (0, 0.020]` 的同一致性掩码（低信噪比兜底）。
- 拉回：`p_V = x + û_V(x)`；用 `oracle.closest` 做**表面贴合门禁** `mesh_d ≤ feature_sdf_limit = max(0.004, scan_offset_tolerance=0.02) = 0.02`。
- 软权重：`exp(−(err/σ_c)²) · exp(−(max(0, mesh_d−0.004)/σ_s)²)`，`σ_c = 0.004/2`、`σ_s = feature_sdf_tolerance=0.004`。
- 聚类：`cKDTree.query_pairs(vertex_cluster_radius=0.003)` → 连通分量 → 支持数 ≥ 4 的分量才成为候选；中心用 **Weiszfeld 加权 L1-median**（4 次迭代，`_weighted_l1_median`）估计，同时记录 `residual`（加权 RMS 展布）、`weight`、`support`。

**E 通道**（`_pull_edge_points`, `:110`）
- 掩码：`dE ∈ [0.003, 0.018] & |‖uE‖−dE| ≤ 0.0035`（`< 8` 点时同样退化），这就是文档说的「标量-向量一致性无监督剔除中轴假零集/短向量拖尾」。
- 拉回 `p_E = x + û_E`，同样过表面贴合门禁并赋软权重；**同时保留源点 `src_xyz`、源 `dV`、源 V 有效性**，供后面做 V 主导切断。

这一步刻意**不做任何连线**：几何拉回与拓扑连线解耦。

### 2.2 第二步：E/V 双向互证 + 自适应解析切断球（`_verify_vertices_with_edges`, `:163`）

对每个 V 候选 `v_cand`：
1. **E 支撑**：以 `e_support_radius = max(0.008, 2.5h) = 0.008` 统计邻域内 `p_E` 数量，`< 3` → `false_vertex_no_edge_support` 剔除。
2. **标量回查**：`provider.evaluate(v_cand)` 的 `dE > e_val_tol = max(0.005, 1.5·0.0035) ≈ 0.00525` → `false_vertex_high_dE` 剔除（真实 B-Rep 顶点必是 E 的零集）。
3. **近重合合并**（`allow_feature_collapse=true`）：`collapse_tolerance=0.005` 内连通候选按权重平均位置、取最大 residual、合并 support。
4. **自适应半径**：`r_i = min(vertex_cut_radius=0.007, 0.35·d_min)`，`d_min` 为最近邻顶点间距 → `VertexNode(id, position, residual, r_i)`。

若 `presence()[1]=='present'` 却一个顶点都没通过，会补一条 `vertex_pull_empty` 诊断。

### 2.3 第三步：V 主导切断（`_cut_edges_by_vertices`, `:226`）

对每个 `p_E` 同时检查三件事，任一落入顶点球即删：
- 源点 `src_xyz` 到最近顶点距离 > 该顶点 `r_i`；
- 拉回点 `p_E` 到最近顶点距离 > 该顶点 `r_i`；
- 源 V 有效时 `src_dV > r_i`。

这样彻底绕开交点处 `uE` 多值跳变 + `dE` 被磨圆的脏区，交点信息完全交给 V 通道；被切掉的部分由后续「端点挂接 + 固定端点拟合」自然补回。

### 2.4 第四步：微体素共识 → 1D PCA 瘦身 → 切向聚类 → EMST 排序

| 子步 | 实现 | 关键阈值 |
|---|---|---|
| 微体素共识 | `_micro_voxel_consensus` `:243` | `voxel = min(0.001, h/3)`；输出加权质心、权重和、投票数；当体素数 > 20 时，单票且最近邻 > `edge_link_radius=0.004` 的孤立体素被删 |
| 1D 加权 PCA 瘦身 | `_pca_thin_and_tangents` `:259` | `pca_thin_radius=0.0032`，`iterations=3`；高斯空间权 × 体素权做局部 PCA，取最大特征向量为切向 `t_i`，线性度 `(λ1−λ2)/λ1`；**仅当横向展布 ∈ [1e-4, 0.0015] 时把点收缩到局部均值切线上**（已极细曲线不收缩保曲率，双峰平行边间隙不收缩防粘连） |
| 位置+切向+横向偏移聚类 | `_cluster_tangent_aware` `:312` | 先丢 `|t|<0.5` 或 `linearity<0.3` 的团块噪声（≥3 个“好点”时才启用）；候选对来自 `edge_link_radius=0.004`；再要求切向夹角 ≤ 42°（`|dot| ≥ cos42°`）且**横向偏移** `d_perp ≤ edge_lateral_tol=0.0018`；连通分量 ≥ 3 点 |
| EMST 直径排序 | `_mst_diameter_order` `:364` | 每簇建欧氏最小生成树 → 两次 Dijkstra 取树上最长路径（自动去环去毛刺） |
| 折线成型 | `_extract_ordered_polylines` `:414` | 弧长 < `0.5h` 丢弃；闭环判据：两端不在顶点球附近、点数 ≥ 6、首尾间隙 ≤ `2.5·0.004 = 0.01`、首尾切向夹角 ≤ 50°；重采样步长 `min(0.0025, h)` |
| 段级验证 | `_verify_polylines` `:450` | 每条折线取 7 个探针，`median(dE) ≤ max(0.005, 1.5·0.0035)` 且 `max mesh_d ≤ 0.02`，否则整段丢弃（剔除残余中轴伪边） |
| 挂接/桥接/短边兜底 | `_attach_and_bridge` `:481` | 见下 |

`_attach_and_bridge` 的三个动作：
1. **切向对齐挂接顶点**：在 `r_v + attach_margin`（`attach_margin = max(0.006, 2h) = 0.006`）内找候选，要求顶点在末端外指切向上的投影 ≥ `−0.003`，打分 `横向偏移 + 0.25·距离` 取最优。
2. **弱边断口桥接**（贪心循环，每轮取最短合法对）：两端都未挂接、间距 < `bridge_max = max(0.015, 3.5·0.004)`、弦向与两端切向均 ≤ 35°、中点 `dE ≤ 0.00525` 且中点离网格 ≤ 0.02 才合并。
3. **极短边兜底**：顶点对间距 ≤ `2.5·0.007 + 0.003`，且中段 5 个探针 `dE ≤ max(0.003, 0.0035)`、离网格 ≤ 0.02、不被已有折线覆盖，则插入直线短边。
4. 未被任何顶点挂接、且弧长 ≥ `2h` 的开段计入 `unresolved`（`dangling_edge_segment`），成为 `wireframe_unresolved` 闸门的输入。

`stats` 会记录 `vertex_pull / edge_pulled_points / edge_after_vertex_cut / micro_voxels / clusters / rejected_segments / timings`，是调参的主要窗口。

## 3. 曲线拟合：`recover_wireframe` + `fit_geometry`（`edge_first_graph.py`）

- 每条 `Path` 的端点若已挂接顶点，`with_endpoints()` 会把**精确顶点坐标**硬插到折线首尾（并按总距离决定是否反转顺序），形成“固定端点参数曲线”问题。
- 拟合器按代价从低到高尝试（`:81`）：
  1. **直线**（两端点定义，解析判别）；
  2. **整圆**（闭环且 sweep > 5.5 rad 时强制 2π）/ **固定端点圆弧** `fit_fixed_arc`；
  3. **分段 C1 三次 Bézier**：`projected_seed()` 在 `spans = 1..max_segments(64)` 上带端点约束最小二乘；失败则先 `_densify_chord_gaps(2h)` 加密弦再重拟，并对结果做 `_curve_near_surface` 复核防跨空过冲。
- 验收 `_curve_accepted()`：全点 `max ≤ curve_tolerance=0.001`；否则若精修点 ≥ 6 用「p95 ≤ tol 且 max ≤ 1.5tol」放宽，同时未精修格点放宽到 `max(tol, 0.75h)`；解析曲线另有「≥12 点 p95 ≤ max(tol,0.6h)」通道。全部失败 → `curve_geometry_failed`。
- 拟合失败不致命：该 path 计入 `unresolved`，其余边继续；顶点若最终没被任何边使用 → `isolated_vertex`。
- **覆盖率诊断**：把所有曲线按 `2h` 采样成 KD 树，统计拉回点云中距离 > `2h` 的点数 `uncovered_support`。
- 输出 `wireframe.json`（顶点/边/未解析/覆盖率/`collapsed_edges`/计时/`skeleton` 统计）、`curves.json`、`edge_support.npz`（PCA 瘦身后的支撑点云，用于评分/可视化）。

闸门（`edge_first.py:103`）：`incomplete = presence.E=='present' and (无曲线 or unresolved or uncovered_support or warnings)`；只有 `allow_partial_wireframe=true` 且已有曲线时才允许带警告继续，否则 `wireframe_unresolved`。

## 4. 面拓扑：`fast_faces` 快速路径 或 `split_mesh` 精确切面

### 4.1 `fast_faces`（`fast_faces.py`，默认开启）
- `coarse_paths()`：把每条曲线采样后，在**原网格边**构成的图上做带权 Dijkstra 路由（走廊半径 `band_width=0.02`，代价 `长度·(1+(偏移/h)²)`，偏好贴曲线短路径），并强制不同逻辑边的内部节点互斥（`coarse_projection_crossing/overlap`）。
- `label_barriers()`：以屏障边断开三角形邻接 → 面标签、每条边的左右面、有向环。
- 每个面用区域法向 RANSAC 拟合平面，`face_polygon` 用曲线环 UV 构造外环+孔环；验收：边界最大偏差 ≤ `boundary_tolerance=0.001`、区域内点支持率 ≥ 85%、`region_area/polygon.area ∈ [0.75,1.25]`。
- 再跑一次**试装配 + STEP 读回**（写到 `planar_trial/`），成功才 `mv` 到正式输出；任何 `ReconstructionError`（`sample_timeout` 除外）都静默回退到精确切面。

### 4.2 精确切面 `split_mesh`（`edge_first_embedding.py`）
- `SurfaceCut.embed()`：对每条三维参数曲线逐点 `locate()` 定位到三角形（自适应吸附 `min(1e-5, 0.05·min_edge)`），在三角形内用**带法向翻转惩罚 + 已占用内部点避让**的 Dijkstra 走廊 `route()` 连接，`_simplify_segments()` 消除往返尖刺；受影响三角形做 `polygonize` + 约束 Delaunay 局部重剖分，其余三角形原样复用（三维线框几何不变）。
- `label_barriers()` 求面标签与有向环，`boundary_cycles.complete_face_regions_and_cycles()` 补全孔环。
- 若两条边 `curve_embedding_overlap`：`allow_feature_collapse` 时丢弃**较短**那条、给保留边打 `collapsed_edges` 标记、重编号并整体重试（最多 5 次）。
- 产物：`split_mesh.npz`（顶点/三角形/面标签/约束）、`logical_graph.json`。

## 5. `surfaces`：解析面 + 自由面拟合（`surface_fitting.py`、`face_patches.py`）

`initialize_face_surfaces()`（`:568`）对每个逻辑面：
1. `sample_face_regions()` 面积加权采样 + `_core_samples()` **腐蚀掉贴边过渡带**（避开扫描件棱边圆化失真）。
2. `analytic_candidates()` 依次给 平面/球/圆柱/圆锥/圆环；两个同心圆边时额外插一个 coaxial `cylinder` 候选。
3. 筛选：核心点 `p90 ≤ 2·surface_tolerance = 0.006`、`max ≤ scan_limit = max(0.006, 0.02) = 0.02`、边界最大偏差 ≤ `boundary_tolerance`（含 collapsed 边时放宽到 `max(boundary_tolerance, collapse_tolerance)`）；平面额外要求边界 ≤ `0.25·tol`。
4. 解析全失败 → `revolution_candidates()`（按 cylinder>cone>torus 排序取最优）；再失败 → `fit_general_spline()`（LSCM 内蕴参数化 + 薄板平滑张量 B-spline）。
5. `_refit_collapsed_edges()`：对受控合并边用两侧解析面 `GeomAPI_IntSS` 求精确交线，替换粗中线并更新顶点。
6. 逐面终检：边界（129/257/513 采样）、核心内点、`|provider.sdf|`、Jacobian 非退化（排除 cone 尖顶 / sphere 极点），违规即 `surface_boundary_incompatible / surface_fit_failed / surface_fold`。
7. `fit_with_patch_fallback()`：上述失败时在面域内部三角形图上找最短内部路径**切一刀**（双连通面优先成对跨环双切，把环面切成两个盘），把接缝注册为新逻辑边+曲线，最多重试 `patch_budget=4` 次，并记录 `patch_to_logical_face` 映射。

## 6. `cad`：OCC 共享装配与 STEP 读回（`occ_assembly.py`）

- 每个逻辑顶点/边只建一次 `TopoDS_Vertex`/`TopoDS_Edge`，逐面挂 `pcurve`（`make_pcurve`，校验中点误差）。
- 周期面 seam 规划：同轴环族统一母线参考方向；环面无全缠绕时旋转 UV 框把 `u` 切口放进角度空隙（免 seam）；异母线用 UV 线性螺旋 seam；`sphere/torus` 显式 seam；`cone` 尖顶 / `sphere` 极点用 `make_conical_cap / make_spherical_cap` 接退化边。
- `verify_export_and_roundtrip()`（`:675`）：体积 > 0 → 可三角化 → 写 STEP → 读回 → `BRepCheck_Analyzer` 有效 → 体积变化 ≤ `max(1e-7, 1e-5·V, 面积·boundary_tolerance)` → 面数 == `graph.face_count` → 所有曲线采样点到读回边的最近距离 ≤ `cad_tolerance = 0.002`；通过后改名 `reconstruction.step`。
- 产物：`reconstruction.step`、`logical_to_cad.json`、`face_patches.json`、`quality.json`（含 `step_sha256`、`face_method`）。

## 7. 阈值速查（默认配置里真正驱动流程的量）

| 参数 | 值 | 作用 |
|---|---|---|
| `fine_spacing h` | 0.003 | scout 末级步长、PCA 邻域/重采样/短边兜底的基准单位 |
| `band_width` | 0.02 | E/V 有效查询带、`fast_faces` 走廊半径 |
| `edge_mid_min/max` | 0.003 / 0.018 | E 通道中场筛选带 |
| `vertex_mid_min/max` | 0.003 / 0.020 | V 通道中场筛选带 |
| `edge_consistency_tol` | 0.0035 | E 的 `|‖u‖−d|` 门限，并派生出 0.00525 的回查容差 |
| `vertex_consistency_tol` | 0.004 | V 的一致性门限，派生 `e_support_radius=0.008` |
| `vertex_cluster_radius` | 0.003 | 顶点拉回点聚类半径 |
| `vertex_cut_radius` | 0.007 | 切断球上限（实际取 `min(0.007, 0.35·d_min)`） |
| `edge_link_radius` | 0.004 | 聚类连边距离、闭环间隙基数 |
| `edge_lateral_tol` | 0.0018 | 防窄倒角平行边串线的横向门限 |
| `pca_thin_radius/iters` | 0.0032 / 3 | 1D 瘦身邻域与轮数 |
| `feature_sdf_tolerance` | 0.004 | 权重尺度；`feature_sdf_limit = max(0.004, 0.02)` 用于所有“离网格”门禁 |
| `curve/surface/boundary/cad_tolerance` | 0.001/0.003/0.001/0.002 | 曲线、曲面、边界、STEP 四级容差 |
| `scan_offset_tolerance` | 0.02 | 解耦的扫描偏移预算（核心内点/门禁用） |
| `allow_feature_collapse` / `collapse_tolerance` | true / 0.005 | 近重合顶点合并、切面重叠丢短边重试 |
