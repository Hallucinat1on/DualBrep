## 0. 总览：统一架构与核心原则

```text
┌─ 网格输入 M ──────────────────────────────┐
│                                           ├─→ 拓扑载体 M（闭合水密流形网格）
└─ 点云输入 (P_raw, N_raw) ──→ 代理网格重建 ─┘      │
        │                  (Screened Poisson /      ├─→ Stage 1: scout（近表面 3D 稀疏二分采样）
        │                   geo_decoder MC)         ├─→ Stage 2: wireframe（8D vector_pull + 固定端点曲线拟合）
        │                                           ├─→ Stage 3: (fast_faces | split_mesh 网格流形切分定面环)
        └── (点云输入时直接映射原始点到切好面域) ────┴─→ Stage 4: surfaces（解析/回转/LSCM + 窄面边界先验兜底）
                                                        ↓
                                                    Stage 5: cad（OCC 周期 seam + 极点退化边 + STEP 读回校验）
```

### 核心设计原则
1. **预处理与 8D 场绝不沿 seam 切面**：完整圆柱、圆锥、球面在 $360^\circ$ 方位角上无几何特征，沿 seam 切面会向 `E-UDF / uE` 引入严重多义性并向 `V-UDF` 注入伪顶点。数据预处理坚持 `ShapeUpgrade_UnifySameDomain` 合并同域面、不把 seam 加入 E 通道；周期面装配统一由 Stage 5 `occ_assembly.py` 显式规划 seam 与极点退化边。
2. **网格定拓扑、原始几何定曲面**：闭合三角网格提供现成的 2D 离散流形（确定性解决非凸鞍点环绕向、$G^1$ 相切面分离、内孔环归属与 LSCM 共形 UV 参数化）；点云输入先构建水密代理网格承载流形切分，曲面拟合阶段直接映射回原始高精度点云 `(P_raw, N_raw)` 消除代理网格平滑误差。
3. **运行与诊断契约**：入口为 `reconstruct()`（网格）与 `reconstruct_point_cloud()`（纯点云）；`Run` 类增量落盘 `run.json` 与最终 `quality.json`，受 `deadline.py` 的 `sample_budget`（默认 `10800s`）与 `checkpoint()` 约束；外部场契约固定为 **8D 连续场** `[dE, dV, uE(3), uV(3)]`，仅在 `|sdf| ≤ band_width (0.02)` 且 `|x| ≤ 1` 内查询。

## 1. Stage 0：统一输入适配（`point_cloud_source.py`）

- **网格输入**：直接经 `validate_mesh()` 校验闭合流形与一致外法向，进入 Stage 1。
- **纯点云输入（`reconstruct_point_cloud`）**：
  1. **一致外法向估算**（`estimate_oriented_normals`）：未提供法向时，局部 PCA 估法向 + 基于 $1 - |\mathbf{n}_i \cdot \mathbf{n}_j|$ 权重的黎曼 MST 传播定向，并以距质心最远点锚定外向符号。
  2. **水密代理网格构造**（`build_proxy_mesh`）：支持直接传入上游 `geo_decoder` 的 MC 网格（`proxy_mesh`），或默认通过 `pymeshlab` Screened Poisson（`depth=8, pointweight=16.0, samplespernode=1.0, threads=1`）+ 重复/极近顶点合并、零面积/退化狭长面清理、非流形修复与正体积定向生成闭合流形代理网格。
  3. **原始点云透传**：`(P_raw, N_raw)` 透传至 Stage 4，通过 `map_point_cloud_to_faces()` 将原始点按最近三角形归属到切分后的面域（过滤距切分网格 `> feature_sdf_limit` 或法向反号点），避免代理网格削圆/平滑污染曲面精度。

## 2. Stage 1：`scout` 近表面稀疏分层采样（`edge_first_grid.py`）

产物 `scout.npz`：`points / keys / values[sdf, dE, dV] / offsets[uE, uV] / valid / blocks`。

1. `candidate_blocks`：对拓扑载体 `M` 按包围盒 ±`band_width` 光栅化出 `H=0.024` 候选块，裁剪到 `[-1, 1]^3`，受 `scout_point_budget`（`4e6`）约束。
2. `scout()` 全程二分 `0.024 → 0.012 → 0.006 → 0.003`（`Config.scout_spacings`）：对块中心 `c`、边长 `s`、半对角 $R = \frac{\sqrt{3}}{2}s$，按 1-Lipschitz 判据 `dE(c) ≤ scout_margin + R` 或 `dV(c) ≤ scout_margin + R`（默认 `scout_margin=0.007`，`0.006` 块覆盖至 `d ≤ 0.0122` 中场带）保留；块中心无效时补查 8 角点并以最近表面投影点兜底。
3. 所有查询点用 64-bit packed 整数键全局去重缓存（`observe()`），末级展开成 `fine_spacing=0.003` 细格批量查询，逐通道保留 `valid`。

## 3. Stage 2：`wireframe` 8D 中场向量拉回与曲线拟合（`vector_wireframe.py`、`edge_first_graph.py`）

### 3.1 8D 向量拉回线框（`extract_vector_wireframe`）
1. **E / V 并行中场单步拉回**：
   - V 通道筛选 `dV ∈ [0.003, 0.020] & |‖uV‖ − dV| ≤ 0.004`，拉回 $\mathbf{p}_V = \mathbf{x} + \hat{\mathbf{u}}_V$，半径聚类（`0.003`，支持数 `≥ 4`）+ **Weiszfeld 加权 L1-median** 定候选顶点；
   - E 通道筛选 `dE ∈ [0.003, 0.018] & |‖uE‖ − dE| ≤ 0.0035`（无监督剔除中轴假零集与短向量拖尾），拉回 $\mathbf{p}_E = \mathbf{x} + \hat{\mathbf{u}}_E$ 并保留源坐标与 `dV`（此步不连线）。
2. **E / V 双向互证 + 解析切断球**：对候选顶点校验邻域 `p_E` 支撑（`≥ 3`）与标量 `dE` 回查（`≤ 0.00525`）剔除假顶点；使用独立于 `collapse_tolerance` 的紧去重半径 `min(0.002, 0.7 * vertex_cluster_radius)` 合并重复顶点（保留间距 `0.002–0.005` 的真实细小特征顶点）；构造自适应切断球 $r_i = \min(0.007,\; 0.35\,d_{\min})$。
3. **V 主导切断**：剔除源点或拉回点落入任意切断球（或 `dV ≤ r_i`）的 `p_E` 点，彻底绕开交点处 `uE` 跳变脏区。
4. **微体素共识 → 1D 加权 PCA 瘦身 → 切向聚类 → EMST 排序**：
   - `voxel = 0.001` 加权质心共识并删孤立单票噪点；
   - 3 轮 1D 高斯加权 PCA（`pca_thin_radius=0.0032`），仅横向展布 `∈ [1e-4, 0.0015]` 时收缩（保曲率、防平行边粘连）；
   - 位置（`≤ 0.004`）+ 切向（`≤ 42°`）+ 横向偏移（`≤ 0.0018`）联合分簇 → EMST 直径排序与闭环识别 → 7 点探针段级 `dE` 回查 → 切向对齐挂接顶点、弱边断口桥接（`< 0.015`）与极短边兜底。

### 3.2 固定端点参数曲线拟合（`fit_geometry`）
- 硬约束首尾共享顶点，按代价递增尝试 **直线 → 整圆 / 固定端点圆弧 → 分段 $C^1$ 三次 Bézier**（必要时弦长加密并做贴面复核），验收容差 `curve_tolerance=0.001`。
- 产物：`wireframe.json`、`curves.json`、`edge_support.npz`。

## 4. Stage 3：网格流形切分定面环（`fast_faces.py`、`edge_first_embedding.py`、`boundary_cycles.py`）

- **纯平面快路径（`fast_faces.py`，网格输入默认开启）**：在原网格边上做走廊 Dijkstra 路由 + `label_barriers` + 平面 RANSAC 拟合与试装配，失败时静默回退至精确切面。
- **精确网格切分主路径（`edge_first_embedding.py` `cut_surface`）**：
  1. `SurfaceCut.embed()` 将每条 3D 参数曲线采样投影到拓扑载体 `M`（带法向翻转惩罚与已占用内部节点避让的走廊路由 + 回退尖刺清理）；
  2. 受影响三角形在局部 2D 平面内经 `polygonize + constrained_delaunay_triangles` 重新剖分，把所有 3D 线框严格嵌入为显式屏障边；若单个三角形内出现两条切割线交叉，自动调用 `unary_union` 对交叉线段做 2D 节点化并将新交点反投影回 3D、同步拆分屏障子段，杜绝 `polygonize` 丢弃交叉切段导致的 `curve_embedding_missing_cut`；
  3. `label_barriers()` 断开屏障边求三角形连通分量，确定性恢复逐三角形 `face_labels`、每条边唯一有向 `(left_face, right_face)` 及 `complete_face_regions_and_cycles()` 完整外环/内孔环；
  4. 若极近边发生 `curve_embedding_overlap`，在 `allow_feature_collapse=true` 下受控丢弃较短重叠边、标记 `collapsed_edges` 并重试（最多 5 次），后续由两侧解析面精确求交重定位。
- 产物：`split_mesh.npz`（或 `face_regions.npz`）、`logical_graph.json`。

## 5. Stage 4：`surfaces` 双源拟合 + 窄面先验兜底 + 内部切缝（`surface_fitting.py`、`boundary_prior.py`、`face_patches.py`）

1. **双源核心点采样**：
   - 网格输入：`sample_face_regions(cut_mesh, face_labels)` + `_core_samples()` 边界腐蚀；
   - 点云输入：优先使用 `map_point_cloud_to_faces()` 映射来的**原始高精度点云** + `_core_samples()` 边界腐蚀（原始点不足时自动回退至代理网格采样）。
2. **极窄面 / 削圆面边界先验兜底（`boundary_prior.py`，吸收 BrepForge §4.2）**：
   - 当 `_core_samples()` 腐蚀后剩余核心点 `< min_core_points (15)` 时，直接由该面精确 3D 外环构造 **Newell 法向 + 2D PCA 局部基 + 平面/低阶二次曲面先验**，在 2D 环内（或超窄条中线）合成干净内部支撑点与法向，彻底消除窄倒角/削圆面缺内点失败。
3. **解析 / 回转 / 自由曲面拟合与内部切缝**：
   - 依次尝试 `analytic_candidates()`（平面/球/圆柱/圆锥/圆环 + 双同心圆同轴圆柱）→ `revolution_candidates()` → `fit_general_spline()`（**LSCM 内蕴共形参数化** / PCA 薄板平滑张量 B-spline）；
   - 对 `collapsed_edges` 用两侧解析面 `GeomAPI_IntSS` 精确求交重定位；
   - 失败时由 `fit_with_patch_fallback()` 在面域内部三角形图上找最短路径切缝（双连通面优先跨环双切），最多 `patch_budget=4` 次。
4. **终检**：全边界（129/257/513 采样）、核心内点、`|provider.sdf|` 与 Jacobian 非退化（排除 `cone` 尖顶与 `sphere` 极点）。产物：`face_patches.json`。

## 6. Stage 5：`cad` OCC 共享装配与 STEP 读回（`occ_assembly.py`）

- 每个逻辑顶点/边全局只构建一次 `TopoDS_Vertex` / `TopoDS_Edge`，逐面挂 `pcurve` 并校验中点误差；
- 全周期面显式 seam 规划（同轴环族参考母线、非全缠绕 UV 框旋转免 seam、`plan_periodic_band` 自动旋转双缠绕环以选取 $|\Delta u \bmod 2\pi|$ 最小的锚点对生成竖直母线或最短螺旋 seam，避免斜向 seam 割穿带缺口周期面边界）+ 极点退化边（`make_conical_cap` / `make_spherical_cap` / 部分旋转面极点退化边）；
- `verify_export_and_roundtrip()` 使用自适应积分精度（`BRepGProp.VolumeProperties(..., 1e-5)`，规避 OCC 默认低阶高斯积分在高节点数 degree-1 pcurve 上的数值振荡）严格校验体积、可三角化、STEP 导出读回、`BRepCheck_Analyzer().IsValid()`、体积变化、面数一致与曲线到读回边最大距离 `≤ cad_tolerance (0.002)`。
- 产物：`reconstruction.step`、`logical_to_cad.json`、`quality.json`。

## 7. 核心参数速查（`configs/default.json`）

| 阶段 | 参数 | 默认值 | 作用 |
|---|---|---|---|
| `scout` | `coarse_spacing / fine_spacing (h)` | `0.024 / 0.003` | 二分稀疏格步长调度与重采样基准 |
