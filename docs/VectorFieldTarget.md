# 8D 联合目标表示（UDF + 3D 最近点位移向量场）与中场零集修正方案

本文档整理了针对当前标量边/顶点无符号距离场（UDF：`[dE, dV]`）在零集附近存在精度瓶颈的根因分析、等价学习目标对比、**8D 联合目标表示 `[dE, dV, uE(3), uV(3)]`** 的完整技术方案、推理与后处理协同升级，以及分阶段验证路线。

---

## 1. 背景与问题诊断：为什么标量 UDF 在零集附近容易停滞

当全局预测 MAE 处于 `0.002` 水平（归一化包围盒尺度 `[-1, 1]`）时，标量 UDF 在零集（$d = 0$，即真实 B-Rep 边与顶点）附近仍会出现明显的断线、粘连与中心线偏移。这不仅是训练欠拟合问题，更包含标量 UDF 本身的两大几何/优化缺陷：

1. **$C^0$ V 形尖点（非光滑奇点）导致的零集抬升（Apex Rounding）**
   - 穿过一条 1D 边或 0D 顶点时，标量距离场 $d(\mathbf{x}) = \|\mathbf{x} - \mathbf{p}^*(\mathbf{x})\|_2$ 呈 V 形折线，在 $d = 0$ 处不可微（梯度从 $-1$ 跳变到 $+1$）。
   - 神经网络（MLP / Transformer + 位置编码）本质上是平滑函数逼近器，天然倾向于把 V 形尖角“磨圆”。结果是在真实 $d = 0$ 处，网络预测值被系统性抬高到 `0.002 ~ 0.005`。
2. **非负单侧偏差（One-Sided Bias）**
   - 相比有符号距离场（SDF）在零集两侧呈 $C^\infty$ 线性穿零、正负误差可相互抵消，UDF 满足 $d \ge 0$。任何预测噪声都只能向正方向偏移，导致零集附近缺乏无偏过零点，极值点位置对微小扰动极度敏感。
3. **固定等值面 Marching Cubes（MC）的脆弱性**
   - 当全局 MAE 达到 `0.002` 且零集被抬升时，固定阈值（如 `r = 0.005`）的等值面提取会同时遭遇两类失效：
     - **零集抬升 > 阈值**：局部等值面直接消失，造成边管壳断线；
     - **窄倒角 / 小圆角（相邻边间距 `< 0.01`）**：两个 `r = 0.005` 的管壳互相融合，造成拓扑粘连。

另一方面，在**中场区域**（例如 `0.004 <= d <= 0.020`），距离场处于线性光滑斜坡上，梯度近似为单位向量（$\|\nabla d\| \approx 1$），信噪比远高于零集附近。因此，突破零集精度的核心思路有两条：
- **短期（不重训网络）**：利用中场高信噪比采样点的梯度反向修正零集（见第 4.2 节）；
- **长期（更换更利于学习的等价表示）**：引入 **3D 最近点位移向量场**，把高余维零集的非光滑 V 形极小值问题转化为 $C^\infty$ 线性穿零问题（见第 3 节）。

## 2. 候选等价学习目标的系统对比

在确定最终表示前，对常见几何目标进行了系统评估：

| 候选目标 | 零集处光滑性 | 中场信息利用率 | 存在的问题与评估结论 |
|---|---|---|---|
| **标量 UDF `d`**（当前方案） | $C^0$ V 形尖点（不可微） | 高（斜率恒为 1） | 零集易被磨圆抬升；单侧非负偏差。适合作为域边界与连续性骨架，不适合单独做亚毫米零集定位。 |
| **8D 联合场 `[dE, dV, uE(3), uV(3)]`**（**推荐**） | **向量场 $\mathbf{u}$ 在零集 $C^\infty$ 线性穿零**；标量场 $d$ 在中轴连续 | **极高**（每个中场点一步直接指向零集） | 仅在中轴/切迹（cut locus，`tie`）处向量场有跳变，但可由现有 `flags` 掩码 + 标量场 $d$ 完美规避。 |
| **纯 6D GDF `[uE(3), uV(3)]`**（仅用 `\|\|u\|\|` 当 UDF） | 零集 $C^\infty$ 线性穿零 | 极高 | **不推荐直接替代 8D**：在中轴面连续过零会产生 `\|\|u\|\| = 0` 的**假零集（伪边/伪顶点）**，且截断远场（`d >= 0.05`）缺乏旋转等变的向量截断常数（详见 3.2.1 节）。 |
| 距离平方 `d²` | $C^1$ 光滑，但零集导数为 0 | 低 | **淘汰**：在 $d \to 0$ 处梯度消失，误差被严重放大（$\Delta d \approx \Delta(d^2) / (2d)$），且 `[0, 0.05]` 平方后动态范围跨越 `2500×`，网络几乎放弃零集监督。 |
| 高斯热图 / 占据场 $\exp(-d^2 / 2\sigma^2)$ | 峰值处平顶（导数为 0） | 极低（$d > 3\sigma$ 梯度消失） | **淘汰**：丢失中场几何线索，局部峰值定位精度反而更差，且 $\sigma$ 难以兼顾窄倒角与大尺度特征。 |
| 单调压缩变换 $\log(1 + \alpha d)$ / $\sqrt{d}$ | 零集尖点变得**更尖锐** | 中 | **淘汰**：放大了 $d = 0$ 处的梯度跳变；且其“重权零集”的收益已基本被现有 M2 损失（SmoothL1 + near_field + zero_loss）覆盖。 |
| 局部 1D 标量 SDF | 理论光滑 | 高 | **淘汰**：对 3D 空间中的 1D 边（余维 2）与 0D 顶点（余维 3），不存在全局一致的内/外符号划分，拓扑上无法定义标量 SDF。 |

**结论**：对于 3D 中的 1D 线框与 0D 顶点，**3D 最近点位移向量场 $\mathbf{u}(\mathbf{x})$ 是标量 SDF 在高余维流形上的唯一自然数学推广**。将标量 UDF 与位移向量场联合监督，可以同时获得二者的全部优势。

## 3. 核心方案：8D 联合目标表示 `[dE, dV, uE(3), uV(3)]`

### 3.1 数学定义

对任意 3D 查询点 $\mathbf{x} \in [-1, 1]^3$，定义 8 维监督目标：

$$
\mathbf{y}(\mathbf{x}) = \big[\, d_E(\mathbf{x}),\; d_V(\mathbf{x}),\; \mathbf{u}_E(\mathbf{x}),\; \mathbf{u}_V(\mathbf{x}) \,\big] \in \mathbb{R}^8
$$

其中：
- $d_E(\mathbf{x}), d_V(\mathbf{x}) \in [0, \tau]$ 为截断标量无符号距离（现行 v4 配置 $\tau = 0.05$，`band_max = 0.04`）；
- $\mathbf{u}_E(\mathbf{x}) = \mathbf{p}_E^*(\mathbf{x}) - \mathbf{x} \in \mathbb{R}^3$ 为指向最近 B-Rep 边上投影点 $\mathbf{p}_E^*(\mathbf{x})$ 的 3D 位移向量；
- $\mathbf{u}_V(\mathbf{x}) = \mathbf{p}_V^*(\mathbf{x}) - \mathbf{x} \in \mathbb{R}^3$ 为指向最近 B-Rep 顶点 $\mathbf{p}_V^*(\mathbf{x})$ 的 3D 位移向量。

**关键几何性质**：
1. **过零集 $C^\infty$ 线性穿零**：穿过一条边或顶点时，$\mathbf{u}(\mathbf{x})$ 在法平面（边）或 3D 邻域（顶点）内呈平滑线性反号变化（$\mathbf{u}(\mathbf{x}) \approx -(\mathbf{x} - \mathbf{p}^*)$），完全消除 V 形尖点与零集抬升。
2. **自校准的零集映射**：任意查询点只需一次加法即可映射到预测零集：
   $$
   \hat{\mathbf{p}}^*(\mathbf{x}) = \mathbf{x} + \hat{\mathbf{u}}(\mathbf{x})
   $$
   不再依赖有限差分求梯度，也不再依赖脆弱的固定阈值等值面提取。

### 3.2 标量场与向量场的角色互补

| 维度 | 标量场 `[dE, dV]` | 位移向量场 `[uE(3), uV(3)]` |
|---|---|---|
| **零集附近（`d < 0.004`）** | 存在尖点圆角化与正偏置 | **$C^\infty$ 线性穿零，亚毫米无偏定位** |
| **中场区域（`0.004 <= d <= 0.020`）** | 光滑可靠，用于筛选有效查询带 | **高信噪比单步投影，将体素/表面点直接拉向边和顶点** |
| **中轴 / 切迹（`tie` 面）** | **全局连续，无跳变** | 方向发生 180° 翻转（多解不连续） |
| **远场截断区（`d >= 0.035 ~ 0.05`）** | 明确指示“非特征区域” | 最近点已截断或无定义 |

因此两者不可互相替代：
- **标量场负责“在哪里有效”**（存在性判断、截断带过滤、识别高信噪比中场、辅助避开中轴）；
- **向量场负责“精确在哪儿”**（零集无偏拉回与线框/顶点高精度定位）。

#### 3.2.1 与 Gradient Distance Function（GDF）的关系及为何不采用纯 6D GDF

本文中的 3D 位移向量场 $\mathbf{u}(\mathbf{x}) = \mathbf{p}^*(\mathbf{x}) - \mathbf{x} = -d(\mathbf{x})\nabla d(\mathbf{x})$ 在数学定义上与 **Gradient Distance Function（GDF）** 完全一致（其模长 $\|\mathbf{u}(\mathbf{x})\|_2 = d(\mathbf{x})$ 即为 UDF）。GDF 最初用于解决开放曲面（余维 1）上 UDF 在零集不可微的问题；本方案将其推广至 **CAD 1D 边（余维 2）与 0D 顶点（余维 3）**，并进一步扩展为 **“带截断标量门控的双通道 GDF（Truncated Scalar-Gated GDF）”**。

在当前的局部截断带与密集 CAD 边场景下，**不能**直接去掉标量 `[dE, dV]`、仅用纯 6D GDF 的模长 $\|\hat{\mathbf{u}}\|_2$ 充当 UDF，原因有三：

1. **中轴/切迹（Cut Locus）处的“假零集”与“短向量拖尾粘连”**：
   以两条间距为 $2r$（如 $x = \pm 0.008$）的平行边（窄倒角/细槽）为例，等距中轴面 $x = 0$ 两侧的真实 GDF 分别为 `(-r, 0, 0)` 和 `(+r, 0, 0)`。连续神经网络穿过 $x = 0$ 时必须连续过零：
   - **误判近边区**：在 $x = 0$ 附近，$\|\hat{\mathbf{u}}\|_2$ 会平滑经过 `0.006 → 0.004 → 0.002 → 0 → 0.002 → 0.004`，导致“先用 `||u||` 判近边区”把中轴面误判为近边区域；
   - **短向量拖尾粘连**：中轴附近被插值压缩的向量长度不足（如 $x = +0.001$ 处 $\hat{u}_x \approx +0.003$），执行 `x + u` 后落在空地 `+0.004` 而非真实边 `+0.008`，将中轴附近的点**均匀涂抹在两条边之间的整条缝隙中**，造成平行边粘连。
   - **8D 解法**：标量头 $\hat{d}$ 在中轴面连续（$\hat{d} \approx r > 0$）。推理时只需通过一致性残差 $\big|\|\hat{\mathbf{u}}\|_2 - \hat{d}\big| < 0.0035$，无需额外求导即可瞬间剔除所有中轴假零集与短向量脏点。
   - *注：理论上纯 GDF 也可借由散度符号区分真假零集（真实零集为汇聚点 $\nabla \cdot \mathbf{u} < 0$，1D 边约为 $-2$、0D 顶点约为 $-3$；中轴假零集为发散点 $\nabla \cdot \mathbf{u} > 0$），但推理时计算散度需要 6× 有限差分或 autograd Jacobian，且对噪声敏感，远不如保留标量头直接。*
2. **远场截断区（`d >= 0.05`）的三难困境（以立方体顶面中心为例）**：
   对于远离边/顶点的平坦面内部（如立方体顶面中心），纯 6D GDF 无论怎么处理远场监督都存在致命矛盾：
   - **远场监督 `u = (0, 0, 0)`**：所有大平面内部均变成 `||u|| = 0`，与真实零集彻底混淆；
   - **远场不监督（mask 掉 `d >= 0.05`）**：平面内部 `u` 无约束自由幻觉，凡是偶然落入 `||u|| < 0.02` 的区域都会凭空长出伪边；
   - **取消 `0.05` 截断、全空间监督全局最近边**：一方面立方体顶面中心是 4 条边的全局 Voronoi 中轴交点，网络过零会在每个大平面正中间凭空造出 `||u|| = 0` 的**假 X 形交叉线框**；另一方面 `FeatureUDFOracle` 无法按 `r = 0.05` 剪枝，预处理耗时暴增一个数量级。
   - **8D 解法**：远场由标量 `d = 0.05` 干净接管，`u` 仅在 `d < 0.035` 且非 `tie` 的局部窄带内监督，推理时 `d > 0.020` 直接滤除全部远场。
3. **额外开销几乎为零**：
   相比纯 6D GDF，8D 仅在 Decoder 输出层多出 2 个标量通道（`< 0.05%` 计算量），却换来了远场可截断、中轴零求导剔除以及 `encode_field` 旋转不变标量输入三大刚需能力：

| 需求 | 纯 6D GDF（用 `||u||` 取代 UDF） | **8D 联合场 `[dE, dV, uE(3), uV(3)]`** |
|---|---|---|
| **区分远场 vs. 近边区** | 无法截断（设 0 混零集、不设则乱猜、全空间则大面中心出假零集） | 标量 `d ∈ [0.004, 0.018]` 直接干净筛选 |
| **剔除中轴假零集与短向量拖尾** | `||u||` 无法识破（需 6× 有限差分求散度 $\nabla \cdot \mathbf{u}$） | `\| \|\|u\|\| - d \| < 0.0035` 单次前向零成本剔除 |
| **额外计算/参数成本** | 6 通道输出 | 仅多 **2 个标量通道**（Decoder 末层 `< 0.05%` 计算量） |

### 3.3 监督掩码、尺度归一化与损失函数

1. **向量场监督掩码（核心防坍缩机制）**
   在两条边或两个顶点的等距中轴面（cut locus）以及截断远场处，最近点不唯一或无定义。若强行监督，网络会在中轴处输出平均零向量。必须构造严格掩码：
   - 边位移掩码：
     `mask_uE = (dE < d_vec_max) & (nearest_ids[:, 0] >= 0) & ((flags & 1) == 0)`
   - 顶点位移掩码：
     `mask_uV = (dV < d_vec_max) & (nearest_ids[:, 1] >= 0) & ((flags & 2) == 0)`
   - 推荐阈值：`d_vec_max = 0.035`（略小于 v4 的 `band_max = 0.04` 和 `udf_truncation = 0.05`，避开截断边界效应）。

2. **尺度归一化**
   由于 `uE, uV` 的模长与 `dE, dV` 同量级（`0 ~ 0.035`），建议与标量场保持一致的尺度归一化（例如统一除以 `udf_truncation = 0.05` 后再回归，推理时乘回 `0.05`），避免向量分量幅值过小导致梯度被标量项淹没。

3. **损失函数设计**
   保留现有 M2 标量 UDF 损失不变（`L_scalar`：SmoothL1 + near_field 加权 + zero_loss），新增向量场监督项：
   $$
   \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{scalar}}(d_E, d_V) + \lambda_{\text{vec}} \mathcal{L}_{\text{vec}}(\mathbf{u}_E, \mathbf{u}_V) + \lambda_{\text{cons}} \mathcal{L}_{\text{cons}} + \lambda_{\text{dir}} \mathcal{L}_{\text{dir}}
   $$
   - **位移回归项 $\mathcal{L}_{\text{vec}}$**：对掩码内样本使用 `SmoothL1Loss`（`beta` 对应原始尺度约 `0.002 ~ 0.003`）。**禁止使用 L2**，以防止未完全剔除的近中轴样本产生平方级惩罚导致预测均值坍缩。可复用 near/mid-field 权重，使零集与中场均保持高精度。
   - **几何一致性项 $\mathcal{L}_{\text{cons}}$（可选，权重较小如 `0.05 ~ 0.1`）**：
     约束 $\big|\|\hat{\mathbf{u}}(\mathbf{x})\|_2 - \hat{d}(\mathbf{x})\big|$（在掩码内），促使标量头与向量头共享几何结构；注意对 $\hat{d}$ 做 `.detach()` 或双向弱耦合，防止标量的零集抬升反向污染向量场。
   - **方向余弦项 $\mathcal{L}_{\text{dir}}$（可选，仅限中场 `0.003 <= d < d_vec_max`）**：
     约束 $1 - \cos(\hat{\mathbf{u}}, \mathbf{u}_{\text{gt}})$，强化中场指向零集的方向精度（零集附近 `d < 0.003` 必须屏蔽该项，避免除以零）。

4. **数据增强等变性**
   v4 训练管线已启用 24 立方体群离散旋转增强（`cube_rotation_aug`）。加入向量目标后，对旋转矩阵 $R \in SO(3)$（作用于点坐标 $\mathbf{x}' = \mathbf{x} R^\top$ 和法向 $\mathbf{n}' = \mathbf{n} R^\top$），必须对位移向量目标同步施加完全相同的旋转：
   $$
   \mathbf{u}_E' = \mathbf{u}_E R^\top, \qquad \mathbf{u}_V' = \mathbf{u}_V R^\top
   $$

### 3.4 网络架构与数据管线改动点（低侵入、低成本）

#### （1）网络与生成框架兼容性
- **`EdgeVertexShapeVAE` 编码端与潜空间完全不变**：几何潜码 `z_g` 与场潜码 `z_f`（`[4096, 64]`）维度不变，现有 `FieldDiT` 流匹配模型（`z_g -> z_f`）与 `encode_field` 无需任何结构修改。
- **仅修改 Decoder 末端输出头（与 M4 无冲突解耦）**：
  - 标量通道 `[dE, dV]` 保持现有 `field_query_decoder.output_proj(2) + M4 [edge_head(1), vertex_head(1)]` 不变（兼容 Run 9 权重热启动）；
  - 向量通道 `[uE(3), uV(3)]` 在 M4 `LocalKnnQueryDecoder` 中新增独立 `edge_vec_head(3)` 与 `vertex_vec_head(3)` 直接输出（归一化至 `u / 0.05`），避免全局低频头在无监督远场区产生漂移；
  - 截断区（`d >= 0.05`）磁盘占位 `(0, 0, 0)` 在训练期严格 Mask 为 0 梯度自由外推，彻底避免 `0.05` 处人工断崖跳变。

#### （2）数据准备成本（几乎零额外 OCC 开销）
- **`uV` 零预处理重跑**：
  现有 v4 数据已保存 `vertex_zero/points.npy`（精确 B-Rep 顶点坐标）和每个查询池的 `nearest_ids[:, 1]`（最近顶点索引）及 `flags`。在 `hy3dshape/hy3dshape/data/surface_pools.py` 加载批次时即可在线零成本计算：
  ```python
  uV = vertex_zero_points[nearest_v_id] - query_xyz
  ```
- **`uE` 零额外 OCC 求解成本**：
  在 [distance.py](file:///opt/data/private/yihengxu/DualBrep/veudf/src/veudf/preprocess/distance.py#L100) 中，OCC 距离求解器实际上**已经算出了精确的 3D 最近投影点 `projected`**，目前仅用于残差校验后即被丢弃：
  ```python
  distance, projected, local_tie = solve(self.tools[index], query_vertices[row])
  ```
  只需在 `distance.py` 的 `reduce_min` 中同步维护 `nearest_points`（`(N, 3)`，`float16` 或 `float32`），并在 `veudf/src/veudf/preprocess/pipeline.py` 中落盘（如 `edge_offsets.npy` 或扩展字段，升级 schema 版本标识），几乎不增加预处理运行时间。
  - *快速消融技巧*：在重跑预处理前，也可以在 `surface_pools.py` 中临时用现有 `edge_zero/points.npy`（65,536 个边零集采样点）做 KDTree/近邻近似 `uE` 以快速验证网络收敛性，正式版本再切换为 OCC 精确 `projected`。

## 4. 推理与后处理协同升级

### 4.1 8D 联合场的“中场单步向量拉回”与交点 V 主导切断（替代脆弱的 `r=0.005` MC）

拥有 `[dE, dV, uE(3), uV(3)]` 后，`band_brep_reconstruction` **完全沿用现有高层范式**（“顶点切断粗糙边 → 锁定共享顶点 → 固定顶点参数化边 → 切面 & 核心采样拟合曲面 → 含退化边 OCC 装配”），下游曲线拟合、面切分与 OCC 装配几乎无需大改；仅将最前端脆弱的 `r = 0.005` MC 管壳/球壳提取升级为 **V 主导切断 + 中场单步向量拉回**。

> **核心设计原则——交点处 `E` 通道跳变的解法（V-Dominated Junction Masking）**：
> 在多条边交汇的顶点 $V$ 周围，相邻边之间的中轴面（`tie` 面）呈辐射状密集交汇，导致 `uE` 必然多值跳变、`dE` 被磨圆抬升。但只要附近没有另一颗紧贴顶点，**顶点向量场 $\mathbf{u}_V(\mathbf{x}) = \mathbf{v}^* - \mathbf{x}$ 在 $V$ 周围整个 3D 球域内完全 $C^\infty$ 光滑无跳变**。因此后处理严格遵循：**交点全权交给 V 通道，提取边时主动切除顶点邻域的 `uE` 跳变脏区**，最后由干净的外部边段在固定端点拟合时严丝合缝地延伸回精确顶点。

具体执行流程如下：

1. **第一步：V 通道中场拉回定精确顶点 + 构造解析切断球（替代原 MC 顶点球壳）**
   - 在 `scout` 稀疏近表面 3D 查询点上筛选高信噪比 V 中场点：
     `0.004 <= dV <= 0.020` 且一致性残差 $\big|\|\hat{\mathbf{u}}_V\|_2 - \hat{d}_V\big| < 0.004$（自动过滤中轴与异常点）；
   - 执行单步向量拉回 $\mathbf{p}_V = \mathbf{x} + \hat{\mathbf{u}}_V(\mathbf{x})$（可选再做 1 步局部细化），使 3D 球壳内数百个中场点坍缩为半径 `< 0.001` 的致密 0D 点簇；
   - 用 DBSCAN / 半径聚类（`eps ≈ 0.003`）分簇，对每簇按一致性权重取加权均值/中位数，直接得到**精确参数化顶点坐标 $\hat{\mathbf{v}}_i$**；
   - 以每个 $\hat{\mathbf{v}}_i$ 为球心构造**解析切断球** $B(\hat{\mathbf{v}}_i, r_i)$（替代原固定半径 MC 顶点球壳）：默认半径 $r_i \approx 0.006 \sim 0.008$；若相邻顶点间距 $d_{\min} = \min_{j \ne i} \|\hat{\mathbf{v}}_i - \hat{\mathbf{v}}_j\|$ 很小，自适应收缩为 $r_i = \min(0.007,\; 0.35 \cdot d_{\min})$，防止近距顶点球互相吞并。

2. **第二步：E 通道中场拉回提取已切断的极细粗糙边线框（替代原 `r=0.005` MC 管壳 + 3D 细化）**
   - 在 `scout` 近表面 3D 查询点上筛选同时满足三条件的干净边中场点：
     - 边中场带：`0.004 <= dE <= 0.018`（避开零集噪声与远场截断）；
     - **标量-向量一致性过滤**：$\big|\|\hat{\mathbf{u}}_E\|_2 - \hat{d}_E\big| < 0.0035$（无监督剔除两平行边之间的中轴假零集，彻底解决窄倒角粘连）；
     - **顶点切断过滤**：不在任何解析切断球 $B(\hat{\mathbf{v}}_i, r_i)$ 内且 `dV > r_i`（直接绕开交点处 `uE` 跳变脏区）。
   - 执行单步投影 $\mathbf{p}_E = \mathbf{x} + \hat{\mathbf{u}}_E(\mathbf{x})$（可选 1 步细化，并再次剔除拉回后落入 $B(\hat{\mathbf{v}}_i, r_i)$ 内的点），此时每条边已天然被顶点球切断，成为宽度 `< 0.001`、互不粘连的独立 1D 骨架点云段；
   - 对切断后的 1D 边点云按“欧氏距离 + 局部 PCA 切向一致性”做连通分支聚类，经局部 PCA / MLS 排序抽稀得到有序粗糙折线（Polylines）；
   - 将折线两端沿末端切向在距离 $\le r_i + \delta$ 范围内挂接到对应的精确顶点 $\hat{\mathbf{v}}_i$（首尾自闭合且不触碰任何顶点球者自然识别为整圆/椭圆等无顶点闭环边）；
   - **极短边兜底**：若两相邻顶点间距 $< 2 r_{\text{default}}$（如极小倒角端边）且中间无足够边点，直接查询两顶点连线中点处的标量 `dE`（若 `dE < 0.003` 且贴近网格表面，直接补出直线短边）。

3. **第三步：固定顶点参数化边与下游装配（100% 复用现有管线）**
   - 将“精确端点 $(\hat{\mathbf{v}}_a, \hat{\mathbf{v}}_b)$ + 干净中间 1D 点云段”无缝喂入现有固定端点参数曲线拟合器（Line / Circle / Ellipse / B-spline），再进入 `fast_faces / split_mesh → _core_samples 曲面拟合 → 含退化边 OCC 装配`。由于中间点云已剥离交点脏区且远细于 MC 管壳，曲线拟合精度与端到端装配成功率同步提升。

### 4.2 过渡方案：针对现有 2D 标量 UDF 的中场梯度零集修正（零重训）

在切换到 8D 联合场之前，若当前 2D 标量 UDF 网络已经训练完成且全局 MAE 停留在 `0.002`，可先在 `band_brep_reconstruction`（`shell_geometry.py` / `skeleton_paths.py`）中用以下无训练后处理方案缓解零集误差：

1. **中场有限差分梯度**：在网格表面及近表面中场带（`0.005 <= d <= 0.020`）以步长 $h \approx 0.003$ 做中心有限差分估计梯度 $\hat{\mathbf{g}}(\mathbf{x}) = \nabla \hat{d}(\mathbf{x}) / \|\nabla \hat{d}(\mathbf{x})\|_2$。
2. **反向梯度拉回（Gradient Pulling）**：
   沿 $-\hat{\mathbf{g}}$ 做 2–3 步带阻尼牛顿/拉回迭代：
   $$
   \mathbf{p}_{k+1} = \mathbf{p}_k - \alpha \hat{d}(\mathbf{p}_k)\, \hat{\mathbf{g}}(\mathbf{p}_k)
   $$
   利用远处光滑斜坡上的精确梯度把点直接推向零集，绕过 $d = 0$ 附近的平底/抬升区。
3. **负散度脊线检测（Negative Divergence）**：
   计算归一化梯度场的负散度 $-\nabla \cdot \hat{\mathbf{g}}(\mathbf{x})$。在真实 1D 边和 0D 顶点处，两侧梯度迎面相撞，负散度呈现尖锐正峰（对标量绝对值抬升完全不敏感），可用于替代固定阈值 `d < 0.005` 的断线重连与种子定位。

> 注意：有限差分方案每次推理需额外 6× 查询开销，且在窄倒角处受限于步长 $h$；因此它定位为 **Stage 0 的即时止血与基线对比手段**，长期仍应升级至原生 8D 向量场（单次前向即可输出解析级位移）。

## 7. 与相关位移/方向场工作（SFCNet、D-FRAME）的本质差异与论文定位

若仅孤立地看“预测指向最近边的 3D 位移向量并将点拉回边上”这一局部操作，本方案与 **SFCNet**（*CAGD 2023*，点云锐特征位移规整）及 **D-FRAME**（*IEEE TVCG*，基于方向场的 CAD 线框提取）在几何直觉上存在交集。但在**任务终点、语义覆盖、场的定义域、学习范式与中轴处理**上，本工作与二者存在结构性差异：

### 7.1 核心维度全景对比

| 对比维度 | **SFCNet** (*CAGD 2023*) | **D-FRAME** (*IEEE TVCG*) | **本工作（DualBrep + 8D 联合场）** |
|---|---|---|---|
| **核心任务与最终产出** | 点云锐化规整（输出**规整后的点云**，无拓扑、无曲线、无曲面） | 线框提取（输出 **PWL 分段线性折线**；配合 RPD 仅输出**多面体/分面网格**） | **Wireframe-First 端到端参数化水密 B-Rep（STEP）**：解析面 + B-spline 自由面 + 退化边 OCC 严格装配 |
| **特征语义覆盖范围** | **Sharp-only 锐边/尖角**（依赖局部二面角突变） | **Sharp-only CAD 棱线**为主（聚焦密集锐边与噪声点云） | **完整 B-Rep 拓扑边与顶点**：同时覆盖锐边、**$G^1$ 光滑相切边**（圆角/圆柱/球面切线）、共面边界、闭环与极点退化边处理 |
| **场的定义域** | **离散输入点云上的逐点映射**（只能在已有输入点上算位移，不能在任意 3D 坐标查询） | **离散输入点云上的逐点特征**（Pointcept 点云骨干输出逐点边概率与方向场） | **近表面三维空间的连续隐式场**（4,096 锚点潜变量 `(z_g, z_f)` 可在任意 3D 坐标按需任意分辨率查询、局部加密重查） |
| **学习与推理范式** | **纯判别式**点云多任务回归（确定性、无全局 CAD 生成先验） | **纯判别式**多阶段流水线（检测 → 精修 → 粗到细启发式连边） | **预训练几何先验 + 条件 Latent Flow (`FieldDiT`, $z_g \to z_f$)**：全局生成式建模，支持拓扑多义性与推理期 **Best-of-N** 选优 |
| **顶点建模与中轴（Cut Locus）处理** | 逐点二分类筛选“近锐边点”+ 回归位移；无显式 0D 顶点场、无中轴切迹屏蔽（密集边中轴易拉偏） | 侧重边点方向场与连接启发式；无独立连续 0D 顶点隐式场，依赖 Refinement 模块修补断点/误检 | **显式双通道 E + V（8D：`[dE, dV, uE, uV]`）**：训练期用 OCC 精确 `flags` 隔离切迹，推理期用**标量-向量一致性** $\big|\|\hat{\mathbf{u}}\|_2 - \hat{d}\big|$ 无监督剔除中轴假零集 |
| **对输入采样/拓扑的依赖** | 强依赖输入点分布（角点或窄边处若缺采样点，无点可拉） | 依赖输入点密度（稀疏处必须靠后处理启发式补全连边） | **完全解耦输入拓扑与采样**：可在网格表面与近表面三维带均匀/自适应重采样，再从中场单步拉回坍缩 |

### 7.2 论文写作与审稿人质疑预案

1. **Related Work 划界**：将 SFCNet、D-FRAME 与 DEF、NerVE、SepicNet 归入 **Point-based Sharp Feature / Wireframe Extraction**，明确其三大边界：① 局限于 Sharp-only 几何折痕（不含 $G^1$ 相切 B-Rep 边）；② 离散输入点上的判别式回归（无生成式全局 CAD 先验与任意 3D 连续查询能力）；③ 止步于点云、PWL 折线或 RPD 多面体网格，不出参数化水密 STEP。
2. **Method 定位**：不将“位移向量学习”作为孤立卖点，而是将其定位为 **“面向连续三维生成式 E/V 隐式场的截断标量门控双通道 GDF（Truncated Scalar-Gated Dual-Channel GDF）”**——专门用于解决高余维零集的 $C^0$ 不可微优化瓶颈，并同步提供“标量-向量一致性中轴假零集剔除”与“截断远场兼容”两项纯位移/纯 GDF 方法不具备的数学性质。
3. **消融实验呼应**：在窄倒角/密集边与 $G^1$ 相切圆角子集上对比 `2D Scalar UDF + MC`、`6D Pure GDF` 与 `8D Scalar-Gated GDF`，直接验证 8D 表示在零集无偏性、中轴假零集抑制与端到端 B-Rep 装配成功率上的不可替代性。

### 7.3 近表面三维窄带（Near-Surface 3D Band）与 8D 向量场的协同增益

与多数仅在输入表面（On-Surface）预测距离场/位移场的工作不同，本方案将 8D 联合场定义在**近表面三维窄带（`band_max = 0.04`）**内（完整 5 项优势与对照实验设计见 [Pipeline.md](Pipeline.md) 第 1.4 节）。当 8D 向量场与近表面 3D 带结合时，会进一步放大两项关键收益：
- **削圆表面上的 3D 跨面拉回**：对于被 MC 或平滑滤波削圆的输入表面点 $\mathbf{x} \in \hat{S}$，8D 位移向量 $\hat{\mathbf{u}}(\mathbf{x}) \in \mathbb{R}^3$ 可直接沿 3D 空间将其拉出圆钝表面、精准还原到空中真实的尖锐棱线与角点；
- **360° 立体中场单步坍缩**：边周围 360° 圆柱中场带与顶点周围 3D 球壳中场带内的大量查询点同时执行 $\mathbf{x} + \hat{\mathbf{u}}(\mathbf{x})$，比仅限 2D 表面的贴面拉回具有更高的信噪比与抗破洞/抗重网格化鲁棒性。
