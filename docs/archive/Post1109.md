## 0. 输入与场接口

### 代码入口与数据契约

模板实现在 `band_brep_reconstruction/bandbrep`，入口有两种：

- CLI：`band-brep-reconstruct --step source.step --output run/`
  - 通过 `cad_source.load_cad_source()` 读取源 STEP，做归一化、目标收集、三角化和焊接，构造精确 `dE/dV`；
  - 支持 `--config`、`--resume`、`--stop-after {seeds,graph,vertices,curves,surfaces,solid}`。
- Python：`reconstruct(mesh, udf, Config(), output_dir)`
  - `mesh` 为已归一化的 `SurfaceMesh(vertices, triangles)`；
  - `udf` 为 `CallableUDFProvider(fn, fingerprint=..., presence=...)`；
  - 恢复器本身不读取任何目标 CAD 实体/边/面 ID。

两种入口均校验生产 `veudf` v3 schema。STEP 路径使用新版 reference 接口查询完整 CAD E/V，训练点池在 0.05 截断。Python 回调需保留有效与饱和掩码，必需查询落在饱和区时会报错。现行几何 condition 版本和数组契约见[预处理说明](../Pre.md)。

`BandState` 的每一行都是一个**三角形中心节点**，不是网格顶点。后续“边带、顶点域、支撑点”都在这张三角形中心图上定义。

### 输入

- 同源 CAD 三角网格，归一化到约 `[-0.9,0.9]^3`；模板校验 `|x| ≤ 1.000001`；
- STEP 入口查询精确 CAD `dE/dV`，Python 入口由调用方提供连续 E/V；
- 表面 SDF 由输入三角网格计算；
- E/V 是否存在由 CAD 目标集合显式给出：`presence=("present"|"absent", ...)`；
  - 禁止 `("absent","present")`：有顶点必须有边；
  - 缺失通道不参与几何，不能当作零距离；
- 所有距离都是归一化坐标中的长度。

### 场查询

`MeshFieldProvider` 把网格 SDF 和外部 UDF 合成三通道 `[SDF, dE, dV]`：通道 0 来自 `veudf.geometry.mesh.MeshSDFOracle`，通道 1/2 来自 `udf.evaluate()`。

- `query_batch_size=65536`；
- 查询域：`|x| ≤ 1.000001` 且 `|SDF| ≤ band_width`（默认 `0.02`）。带外点写入哨兵 `EMPTY_DISTANCE=2√3` 并标为 invalid；`query_report.outside_band` 记录数量；
- UDF 梯度：对空间邻点做**中心差分**，步长 `1e-5`；当前实现不再接受解析/autograd 梯度回调，统一走 `sampled_udf_gradient()`；
- 差分时中心点和 6 个空间探针都必须：
  - 在 `domain_mask` 内（`|x| ≤ 1.000001` 且 `|SDF| ≤ band_width`）；
  - 有效、未饱和、有限；
  - 中心距离 `> 1e-8`，否则梯度无效；
- 投影更新的位置越界时用 `bounded_update()` 做最多 16 次二分回退，`query_report.backtracked_steps` 记录次数；不会把点投影回网格；
- `checked_values()` 要求所有 `present` 通道 valid、非饱和、有限，否则 `invalid_field_query`；
- `MeshFieldProvider.fingerprint` 由 mesh hash、UDF fingerprint、`band_width`、presence、差分方法和 normalization 组成；若 UDF 自带 `mesh_fingerprint` 且与输入网格 hash 不一致，报 `condition_mismatch`；
- `field_error=0.0002` 是误差预算/Huber 尺度，不是人工注入噪声；
- 逐点查询日志不落盘，阶段产物保存所需中心场与统计；
- 单例默认时间预算为 `10800s`，由 `sample_budget` 与 `checkpoint` 协作检查。

## 1. `mesh`：验证原始网格

`validate_mesh()` 检查：

- 顶点有限、三角形索引有效；
- 坐标 `|x| ≤ 1.000001`；
- 每条边恰好两个三角形；
- 半边方向一致；
- 无零面积三角形；
- 总有向体积为正；
- 记录连通分量、欧拉特征、面积、边长/面积分位数。

`validate_mesh()` 记录 `vertices/triangles/edges/components/euler/area/volume/edge_quantiles/area_quantiles`。原始网格保存为 `input_mesh.npz`，并作为**整个流程的 SDF 基准和模型 condition**。后续加密只改变采样三角形，不改变几何。

## 2. `coarse_refinement`：纯几何粗加密

- 目标边长 `refinement_coarse_edge=0.03`；
- **不查询任何场**；
- 标记所有长度 `>0.03` 的全局共享边；
- 每条标记边只建一个中点；
- 按三角形被切 0/1/2/3 条边的 8 种情况做 red/green 一致剖分，邻面通过共享边过渡，避免 T 接头；
- 2 条切边时按剩余四边形的较短对角线选择三角化；
- 迭代到全网格最长边 ≤ `0.03`；
- 每次切分维护 `parent_triangles`，最终 `coarse_mesh.npz` 保存 `vertices/triangles/parent_triangles`；
- `refinement_report()` 再次检查 `(components,euler)` 和 `area/volume` 不变，失败报 `refinement_topology_changed` / `refinement_geometry_changed`；
- 进度写入 `coarse_refinement_progress.json`。

目的：原生 CAD 网格可能有极长平面边，先把跨度压下来，避免后续直接在长边上反复查询 E/V。

## 3. `fine_refinement`：E-only 近场细加密

### 3.1 选区

本轮细加密**只根据 E 场**选近场：

```text
near = (min(顶点 dE) - 最长边 <= 0.02)
       OR (三角形中心 dE <= 0.02)
```

历史配置中的 `refinement_rho_vertex` 为兼容字段。模板细加密选区只使用 E 场。

### 3.2 切哪些边

```text
selected_face = near AND 最长边 > 0.003
marked_edge = 属于 selected_face AND 该边长度 > 0.003
```

只切近场中仍然超长的边，已经 ≤0.003 的短边不切。邻面通过共享边做必要过渡，避免 T 接头。

### 3.3 场查询与停止

- 首轮对粗网格全部顶点查询一次 E/V，后续只追加新顶点；
- 每轮重新查询当前所有三角形中心；
- 当没有 selected 面时停止，报告 `target_reached=True` 和近场最长边；
- 进度写入 `fine_refinement_progress.json`。

最终保存：

- `working_mesh.npz`：细网格 + 组合后的原父三角形映射（`coarse_parent[fine_parent]`）；
- `center_fields.npz`：最终三角形中心坐标、三通道值、provider 指纹。

`CenterFields.validate()` 在复用前检查：

- provider fingerprint 一致；
- 点坐标与最终三角形顺序逐位一致；
- 所有 `present` 通道有限；E/V 的 `present` 通道非负。

这些中心场在下一步 `bands` 中直接复用，避免重复查询。

## 4. `bands`：单阶段面核心 + 边带 + 局部顶点域

默认配置：

```text
face_threshold1 = 0.003
face_filter_size = 10
face_avg_udf_threshold = 0.003
```

`BandState` 的字段：`points/values/edge_band/vertex_band/edge_region/core_mask/face_labels/exclusion_reasons`，另外可选 `vertex_labels/vertex_centers`。`values` 为 `[SDF,dE,dV]`，`points` 是三角形中心。

### 4.1 面核心：只跑第一阶段

对最终网格的三角形中心 `dE`：

1. 保留 `dE ≥ 0.003` 的三角形；
2. 按**三角形共享边**求连通分量；
3. 过滤：
   - 三角形数 `< 10` 的分量；
   - 平均 `dE ≤ 0.003` 的分量；
4. 剩余分量就是 face core。

模板只有第一阶段分割。

原因码：

- `0`：面核心；
- `1`：第一遍低距离；
- `3`：大小过滤；
- `4`：均值过滤；

### 4.2 边带传播

E 存在时，边带包含所有非核心三角形：

```text
edge_band = ~face_core
```

即所有非核心节点都参与标签传播，但原因 3/4 的点仍然不作为边/顶点几何支撑。代码中 `support = (exclusion_reasons == 1)`；`support_nodes` 只保留这些低 `dE` 节点，供顶点/曲线几何使用。

最终 `bands.npz` 保存 `points/values/edge_band/vertex_band/edge_region/core_mask/face_labels/exclusion_reasons`，以及可选的 `vertex_labels/vertex_centers`。`bands.report` 记录 `nodes/edge_nodes/vertex_nodes/regular_nodes/core_nodes/excluded_nodes/exclusion_counts/sampling/vertex_domains/segmentation/field_query_points/reused_center_queries/strict_topology_guarantee` 等统计。

### 4.3 局部顶点域

在边带中选：

```text
seed = edge_band & support & dV < tau_vertex(0.02)
```

对每个 seed：

1. 用 `dV` 的差分梯度投票：
   ```text
   vote = x - dV * grad(dV) / ||grad(dV)||
   ```
2. 投票按 `max(2*localization_tolerance, 4*field_error)` 聚类，默认约 0.002；
3. 至少 3 票的簇取中位数作为候选顶点；
4. 候选半径：
   ```text
   r = min(0.02, max(0.45*gap, 1.5*w))
   ```
   - `gap`：最近其他候选间距；
   - `w`：附近支撑点 `dE` 的 95 百分位。缺少支撑时使用 `vertex_width_fallback=0.01`，对应历史配置的 `face_threshold2` 回退值；
5. 每个边带点归最近候选，且距离 `< r` 才进入该顶点域；
6. 不同候选即使球域相接也保留不同 ID。

输出：

```text
vertex_band = 所有局部域成员
edge_region = edge_band & ~vertex_band
```

局部顶点域报告还包含 `seed_nodes/candidates/merge_radius/radius_fraction/cut_factor/domains/dropped_empty_candidates/radius_min/radius_max/cut_limited`。空域候选会被丢弃并重映射标签；`cut_limited` 统计有多少候选的半径被 `vertex_cut_factor*w` 限制，而不是被候选间距限制。

## 5. `graph`：无方向实例关联

邻接使用**三角形共享网格顶点**（`vertex_adjacency`），比共享三角形边更宽松，能连接仅在角点相遇的节点。`contacts` 是相邻节点对中不属于同一 face core、同一 edge 实例、同一 vertex 域的对。

- 对 `edge_region` 做连通分量，每个分量获得一个 `edge_id`；
- 从 `contacts` 收集 `face ↔ edge`、`face ↔ vertex`、`edge ↔ vertex` 关系；
- 每条边的 `faces` 是它接触的全部 face core 标签；
- 每个顶点域吸收接触的 face labels 和 edge IDs，并进一步吸收这些 edge 的 faces；
- 顶点域不向普通边回传标签；
- 输出无方向的 E–F、V–E、V–F 关联；
- `nodes` 是该实例包含的全部三角形中心节点；`support_nodes` 只保留 `reasons==1` 的节点；
- 恰好两个面的边标 `supported`，其余保留完整标签集合并标 `unresolved`；
- `report` 记录 `unresolved_edges/vertex_domains_without_edges/edges_without_geometry_support/vertices_without_geometry_support` 等。

普通边实例建立后执行短边推断。两个顶点域直接接触且还没有边连接时，检查其投票中心连线上的 33 个采样点，要求全部在 `domain_mask` 内，且 `dE ≤ 2*localization_tolerance=0.002`、`|SDF| ≤ feature_sdf_limit=0.004`。共享面超过两个时，按各面核心距线段中部的距离排序。第三近距离至少为第二近距离的 1.5 倍才取最近两面。最终确定两个邻面时创建 `status='inferred_short'` 的边实例，并写入两个顶点的 `edges`。`short_edges` 报告记录 `contact_pairs/inferred/rejected` 及拒绝原因。

这一步只建立**实例和关联**，还不做方向、端点使用次数和曲线拟合。

## 6. `vertices`：顶点定位

对每个顶点域：

1. 取 `support_nodes` 的边带点（缺失时回退到 `nodes`），要求非空；
2. 用 `dV` 差分梯度投票，取中位数作初值 `v`；
3. 初始球壳半径 `max(8*localization_tolerance, min(0.2*tau_vertex, 0.01))`；
4. 在 `v` 周围生成 120 个随机单位方向，在 `v + direction * radius * U(0.5,1)` 的球壳上查询 `dV`；若球壳越出 `domain_mask`，半径减半重试；
5. 用距离中心拟合：
   ```text
   min Σ ρ(||x_i - center|| - dV(x_i))
   ```
   - `distance_center()` 先用线性最小二乘从 `(x_i, dV_i)` 解出初始中心，再用 `least_squares(loss='soft_l1')` 鲁棒精化；
   - 线性系统秩不足时使用投票初值；
6. 最多 8 轮；若残差 `≤ localization_tolerance` 且中心移动小于当前半径则提前停止，否则半径减半；
7. 残差必须 ≤ `localization_tolerance=0.001`；
8. 最终中心还要满足：
   - `dV ≤ 0.001`；
   - `dE ≤ 0.001`；
   - `|SDF| ≤ 0.004`。

输出 `VertexNode(id, position, residual, support_radius)` 到 `vertices.json`，阶段报告记录顶点数和最大残差。失败码包括 `vertex_support_insufficient`、`vertex_gradient_invalid`、`vertex_rank_deficient`、`vertex_mixed_support`、`vertex_geometry_invalid`。

## 7. `curves`：直接距离拟合

### 7.1 每个边的观测

每个 `topology.edges` 实例：

- 取 `support_nodes` 的边带点 `points`（缺失时回退到 `nodes`）；
- 取缓存的 `bands.values[:,1]` 作为这些点的原始 `dE` 观测 `distances`；
- 不使用最近 CAD 实体 ID；
- 不使用 UDF 梯度参与参数优化。

每条边必须有两个邻面及最多两个顶点候选，否则 `edge_neighbors_unresolved` / `edge_vertices_unresolved`。具有两个端点的推断短边（`status='inferred_short'`）或支撑点少于三个的边使用两个端点作为零距离观测。该分支只接受通过验证的直线。

支撑半径 `radius=max(3*tau_edge, 4*surface_tolerance)`，用于限制投影步长和辅助顶点范围。正常边至少需要 3 个支撑点，否则 `edge_support_insufficient`。

### 7.2 分支顺序

#### ① 直线

如果边有两个固定端点，且端点距离大于 `localization_tolerance`：

```text
C(t) = (1-t)*p0 + t*p1
```

直接拿这条线去验证原始距离观测。通过就采用，**跳过投影和参数优化**。

#### ② 投影与圆 / 圆弧

如果直线不通过：

- 用 `representative_indices()` 从支撑点中做确定性空间覆盖抽样：先在有界池中随机取 `4*count` 个点，再做最远点采样；默认 `curve_init_samples=256`；
- 用 E 场差分梯度做最多 8 轮投影：
  - 只移动 `dE > 0.02*curve_tolerance` 的点；
  - 步长 `0.8*min(dE, 0.3*radius)`，方向为负梯度方向；
  - 每步用 `bounded_update()` 回退越界；
  - 累计位移不能超过 `radius`；
- 投影后要求至少 3 个点，且 ≥80% 满足 `dE ≤ curve_tolerance` 且 `|SDF| ≤ feature_sdf_limit`，否则 `edge_localization_failed`；
- 圆候选：
  - 两个固定端点 → `fit_fixed_arc()`：圆心在弦中垂线上，圆弧精确过两端点；
  - 一个/无端点 → PCA 平面 + 代数圆拟合；
  - 固定端点圆弧要求 ≥95% 投影点落在扫掠角内；
- `refine_circle_distance()` 在最多 `curve_fit_samples=512` 个距离观测上做 Huber 优化，变量只有圆心、轴倾角、半径等少数参数，`max_nfev=15`；
- 保持端点约束，数值导数只针对候选圆几何。

#### ③ 自由曲线：分段三次 Bézier

圆也不通过时：

- 先确定点的顺序：
  - 若投影点本身能拟合圆且误差 `≤ curve_tolerance`，用 `circle_order()` 按角度排序；无端点闭合圆弧还要检查最大角度缺口 `< max(0.35, 8*median_gap)`，否则 `curve_closure_unobserved`；
  - 否则用 `order_general()`：空间网格去重 → kNN 图（`k=min(8,N)`）→ 要求连通 → MST 骨架 → Dijkstra 找路径；有 2 个端点时从端点起止，无端点时用两次 Dijkstra 直径切环；闭合路径首尾距离须 `≤ max(8*step, 4*curve_tolerance)`；最后用点到折线段距离检查覆盖，最大 `≤ 3*curve_tolerance`，否则 `curve_support_branching`；
- 有顶点约束的曲线从 **1 段**开始，单顶点闭环在两端使用同一顶点；
- 无顶点的周期闭环从 **4 段**开始（`breaks=linspace(0,1,5)`），首尾点、切向都周期一致；
- 共用连接点，约束 **C0、C1 连续**；固定端点或周期接缝；
- 约束写成线性等式，`continuity_nullspace()` 用 `scipy.linalg.null_space` 求零空间；控制点只在零空间中更新，因此 C0/C1 和固定端点始终精确满足；
- 初始控制点由 `constrained_lstsq()` 在硬等式约束的零空间中求最小二乘，并对投影点做几轮鲁棒重加权；
- 优化控制点，使：
  ```text
  distance(p_i, C) ≈ observed dE(p_i)
  ```
- 使用 Huber 鲁棒损失，`f_scale=max(field_error, 1e-6)`；
- 雅可比由 Bézier 基函数和曲线法向解析给出，不需要查询 UDF；
- 样条目标另含弱控制点二阶差分平滑项，强度 `1e-4/sqrt(len(regularizer))`；每次最小二乘调用的函数求值上限 `max_nfev=15`；
- 必要时：
  - 增加困难观测点，最多 `curve_refine_samples=2048`；
  - 对最大残差 span 做精确 de Casteljau 细分（曲线几何不变，只增加自由度）；
  - 同时用有序投影点重新生成一个鲁棒初值，比较二者在原始距离观测上的平均残差，选更好的；
  - 最多 `max_segments=64` 段。

初始化阶段：

- `curve_init_samples=256` 个代表点；
- 最多 8 轮梯度投影；
- `curve_fit_samples=512` 个初始距离拟合点。

**注意**：初始化用差分梯度做投影；但 Bézier/圆参数优化本身只使用缓存的原始距离观测，**不查询 UDF 梯度**。

### 7.3 候选验证

每条候选必须通过：

| 检查 | 阈值 |
|---|---:|
| 原始距离观测残差最大值 | `curve_tolerance=0.001` |
| 曲线上采样点 E-UDF | `2*curve_tolerance=0.002` |
| 曲线上采样点 `|SDF|` | `feature_sdf_limit=0.004` |
| 固定端点移动 | `<1e-8` |
| 曲线到观测支撑的覆盖 | `≤ tau_edge=0.025` |
| 曲线验证点数 | 至少 500 |

其中“支撑覆盖”用：

```text
distance(curve_sample, nearest_observation) - observation_dE
≤ tau_edge
```

防止曲线跑到另一个 E 零分支上。

验证采样点数由曲线折线长度决定：

```text
count = max(500, ceil(length/(curve_tolerance*0.5))+1)
```

`record.residual` 记录最大距离残差。

### 7.4 独立全局覆盖

每条曲线单独通过还不够，还要检查有没有漏掉的 E 零分支：

1. 从 `E < tau_edge*0.6 = 0.015` 区域取最多 2048 个点；
2. 做 8 轮 E 差分梯度投影；
3. 每条恢复曲线采 4097 点建 KD-tree；
4. 投影探针到最近曲线点的距离必须 `≤ 3*curve_tolerance=0.003`。

失败码：`edge_valley_unrepresented`、`edge_coverage_unobserved`、`edge_coverage_unlocalized`、`edge_coverage_missing` 等。

全局覆盖仍需要差分梯度。

### 7.5 曲线阶段产物

- `logical_graph.json`：顶点、边实例和拟合报告；此时 `left_face` 仍为 -1，`cycles` 由下一阶段 `postprocess` 填充；
- `curves.json`：每条边的 `CurveRecord(kind/data/residual)`；
- `refined_geometry.npz`：每条边采样点、顶点位置；
- `curve_recovery_progress.json`：按边进度、计时、尝试记录。

阶段报告记录 `coverage`、`kinds`、`method='direct_distance'`、`max_fit_error` 和 `distance_fitting` 细节。

## 8. `postprocess`：边界方向与有向环

对每条曲线在 `t∈[0.05,0.95]` 采 64 个点，避开端点：

- 对每个邻面，用 cKDTree 找最近 face core 三角形中心；
- 用网格法向 `n`、曲线切向 `t`、指向面内部的向量 `a` 计算：
  ```text
  score_f = median( (n × t) · a )
  ```
- 两个邻面的 score 必须异号，否则 `boundary_orientation_ambiguous`；
- 正号侧记录为 `left_face`，建立 `CoedgeUse(face, edge, forward)`；
- 每个面收集所有 incident coedge：闭合边单独成环；开放边按端点匹配串成 wire，每一步必须在剩余 coedge 中找到唯一的下一个 use，否则 `face_sector_ambiguous`；重复使用报 `wire_repeated_use`，不能闭合报 `wire_not_closed`；
- 结果写入 `graph.cycles[face]`，并保存为 `cad_graph.json`。

这一步不建立 seam，也不展开周期参数。

## 9. `surfaces`：固定共享边界拟合曲面

### 9.1 面内采样

- `sample_face_regions()` 在该 face core 的三角形内做局部 NumPy 面积加权采样，默认 `face_samples=1200`，同时返回每个采样点所属三角形的法向；
- 边存在时，尽量保留 `dE > tau_edge/2 = 0.0125` 的可信内部点；
- 至少 20 个才启用该筛选，否则保留原采样；
- 每条关联曲线采 65 点作为**已冻结**的边界约束；第一个内部点记为 `orientation_point`，用于后续面定向。

### 9.2 候选曲面

`analytic_candidates()` 生成第一组候选：

- **平面**：对内部点 + 边界点做 PCA；若边界点本身共面（最大偏差 `<1e-5`），用边界点的均值和法向重新定义平面；
- **球面**：代数最小二乘初始化球心/半径，再对径向残差做 `least_squares`，最多 40 次；
- **圆柱**：从法向 PCA 轴和点云 PCA 轴分别建立局部 UV，代数圆拟合得到初始轴/圆心/半径，再联合优化轴、圆心、半径，最多 60 次；
- **同轴等半径圆特例**：若两条关联边都是圆且半径差 `< boundary_tolerance`，直接插入一个圆柱候选并放在最前。

第一组全部失败时，`revolution_candidates()` 尝试旋转拟合的圆柱、圆锥和圆环面：

- 轴候选来自：边界圆的圆心/法向、两条边界圆圆心的连线、法向统计（中心化/未中心化）；
- 对每个轴候选分别拟合子午线 profile：圆柱 `rho-r=0`、圆锥 `rho-r0-kz=0`、圆环 `hypot(rho-R,z-zc)-r=0`；
- 轴、圆心和 profile 参数联合优化，最多 200 次；
- 边界点权重为内部点的 3 倍（边界曲线已由 E 场精确定位）；
- 按 `cylinder > cone > torus` 的简单优先顺序采用第一个通过筛选的类型。

接受条件：

- 内部点到曲面最大偏差 ≤ `2*surface_tolerance=0.006`；
- 边界偏差 ≤ `boundary_tolerance=0.001`。

筛选时计算 `interior_error=max||patch(uv(p))-p||` 和 `boundary_error=max||patch(uv(boundary))-boundary||`，综合分数为 `mean(interior_error)+boundary_error`。平面只有在 `boundary_error ≤ 0.25*boundary_tolerance` 时才优先，否则浅圆柱会被错误压成平面；若筛后集合为空则恢复原合格集合。没有平面时选综合分数最小的候选。

### 9.3 B-spline 回退

解析候选都不通过时：

- 用内部点 PCA 建立局部 `(u,v)` 平面，并把内部点和边界点的联合包围盒归一化到 `[0,1]^2`；
- 三次张量积 B-spline，节点向量为 `[0,0,0,0, 内部均匀节点, 1,1,1,1]`；
- 控制点每方向从 `8` 到 `16`，每次加 2；
- 每条边的 65 个边界采样点作为**硬等式约束**：
  ```text
  min ||A P - X||² + λ||P||²
  s.t. B P = C_boundary
  ```
  - `constrained_lstsq()` 用 `scipy.linalg.null_space(B, rcond=1e-11)` 求零空间，`λ=1e-8`；
  - 若 `max|B P - C| ≥ 1e-7`，报 `boundary_constraints_conflict`；
- UV 更新 `uv_iterations=4` 轮：每轮用当前 patch 反投影，Newton 迭代 5 次，`J^T J + 1e-10 I`，步长限制 `±0.1`，UV 裁剪到 `[0,1]`；
- 每轮 UV 更新后重新求解一次等式约束，避免约束过期；
- 若在 `max_spline_controls` 内仍无法满足边界，报 `surface_boundary_incompatible`。

### 9.4 曲面验收与产物

对每个面：

- 对每条 incident 曲线，在 129/257/513 三个分辨率上采样并反投影到 patch，最大误差 `≤ boundary_tolerance`；
- 面内采样点拟合误差 `≤ 2*surface_tolerance`；
- 这些点的 `|SDF| ≤ 2*surface_tolerance`；
- 参数化 Jacobian `||∂S/∂u × ∂S/∂v|| > 1e-10`，否则 `surface_fold`；
- `patch.report` 记录 `boundary_max_error/interior_max_error/sdf_max_error/jacobian_min/continuous_boundary_guarantee=False/global_self_intersection_certified=False/boundary_check_samples_per_edge=513/periodic_u`；
- `face_patches.json` 保存每个面的 `kind/data/normal/report`。

失败码：`boundary_constraints_conflict`、`surface_boundary_incompatible`、`surface_fit_failed`、`surface_fold`。

## 10. `cad`：周期规划、共享拓扑与 STEP

模板启用周期规划，`cad_tolerance=0.002`，`boundary_tolerance=0.001`。

### 10.1 周期规划

- **同轴环族**：周期面的 incident 边若恰好是两条闭合圆（球面允许一条），归为 ring face；共享边的 ring face 用并查集合并成族；每族选一个共同子午参考方向，统一 patch 的 `x/y`，并把共享圆的 `start` 旋到同一子午线上；
- **无 seam 布局**：周期面的边界若都是开放的，且 UV 角度上最大空隙 `≥0.05 rad`，旋转参数框架把 `u` 切线放进空隙中心，这样不需要 seam；
- **环链**：把每个 loop 的 pcurve 按整数个 `2π` 平移，使 loop 在 UV 中只在一个顶点处断开；闭合环起点也对齐到该顶点的子午线；若同一面还有闭合环，把开放 loop 整体移到闭合环所在周期，便于 `FixMissingSeam()` 合并顶点而不是替换共享边；
- **显式 band seam**：圆柱/圆锥面若边界由两个各绕一圈（`turn≈±2π`）的 loop 组成，`plan_periodic_band()` 把两个 loop 都平移到 `[u_a, u_a+2π]`，`u_a` 是锚点顶点所在子午线；非绕圈 loop 必须严格落在带内作为孔，否则放弃该布局；按 `v` 排序得到上下边界；
- `make_periodic_band()` 用上下 loop 的锚点顶点生成一条直线 seam，并给 seam 在 `u_a` 和 `u_a+2π` 各建一条 2D pcurve，再按“下环 +u → seam 向上 → 上环 −u → seam 向下”构造逆时针 UV wire；
- **显式周期环带**：两个闭合圆边界 → `make_periodic_annulus()`，用一条子午线 seam 连接上下环；圆环面还要判断保留哪一段管面；
- **球冠**：一个闭合圆 + 极点 → `make_spherical_cap()`，极点用退化边表示；
- 没有显式规划时才用 `ShapeFix_Face::FixMissingSeam()`，并在修复后按 `IsSame` 检查所有逻辑共享边仍然存在。

### 10.2 共享 OCC 顶点和边

- 每个逻辑顶点只建一个 OCC Vertex，所有相邻面共用；
- 每条曲线只建一个 OCC Edge，面只引用共享边，不逐面重建近似边；
- 闭合无顶点环补 `closed_loop_anchor`，不计入逻辑顶点；
- 曲线到 OCC 的映射：
  - `line`：1 次 B 样条，两个极点，参数区间 `[0,1]`；
  - `circle`：`Geom_Circle`，轴向 `normal*sign(sweep)`，起始径向为 x 方向，参数区间 `[0,|sweep|]`；
  - `bezier_spline`：`Geom_BSplineCurve`，breaks 为节点，多重度 `[4,3,...,3,4]`，参数区间 `[0,1]`；
- 有端点时用共享顶点构造边；无端点闭合环用曲线起点创建辅助顶点。

### 10.3 pcurve 与 seam

- 支撑曲面：`plane/cylinder/sphere/cone/torus/bspline` 分别映射到对应 `Geom_*Surface`；
- 每个 edge–face 建一条 pcurve：
  - 平面上的圆 → 精确 `Geom2d_Circle`（含方向 sense）；
  - 其他情况 → UV 空间采样后拟合 1 次 `Geom2d_BSplineCurve`；采样数从 65 逐步加密到 129/257/513/1025，直到“UV 中点插值 → 3D 点”的误差 `≤ boundary_tolerance/2`；最终误差必须 `≤ boundary_tolerance`，否则 `pcurve_fit_failed`；
  - 周期面用 `shift_periods()` 或整周期 offset 把 pcurve 移到 `[start,start+2π)` 的同一周期；
- 用 `BRep_Builder.UpdateEdge()` 挂 pcurve，再 `Range()` 设参数区间；
- 按 `graph.cycles` 构造 wire，coedge 方向不对时用 `Reversed()`；
- 面参数化法向与网格法向相反时：非显式周期面反转全部 wire 再反转 face；显式周期面（band/annulus/cap）直接反转 face，保证 UV 和 3D 约定一致；
- 所有边执行 `SameParameter()`；每个面通过 `BRepCheck_Analyzer`，失败时写 `rejected_face_{id}.brep` 并报 `cad_face_invalid`。

### 10.4 实体与 STEP

- 按共享边的面邻接图求连通分量，每个分量建一个 shell；
- 恰好一个 shell 体积为正（外壳），其余允许为负（内腔），否则 `unsupported_multi_solid`；
- `breplib.OrientClosedSolid(solid)` 定向；
- 每条逻辑共享边必须恰好被两个不同面以相反方向使用，否则 `cad_incidence_invalid`；
- 所有 Vertex/Edge/Face 的 OCC 容差最大值不超过 `1.01*cad_tolerance`，否则 `cad_tolerance_exceeded`；
- `BRepCheck_Analyzer(solid).IsValid()` 必须为真，否则 `cad_solid_invalid`；先写 `curves_and_faces.brep`；
- 导出 `reconstruction.unverified.step`，读回后检查：
  - 读回 solid 通过 `BRepCheck_Analyzer`；
  - 体积变化在预算内：
    ```text
    budget = max(1e-7, |V|*1e-5, surface_area*boundary_tolerance)
    ```
  - 读回 face 数等于逻辑 face 数；
  - 每条逻辑曲线采 33 点，到读回全部边集合的最近距离 `≤ cad_tolerance=0.002`；
- 全部通过才改名为 `reconstruction.step`。

### 10.5 CAD 阶段产物

- `curves_and_faces.brep`：装配后但未做 STEP 读回验收的 BREP；
- `reconstruction.unverified.step`：通过 OCC 检查、待读回验收的 STEP；
- `reconstruction.step`：读回验收通过后的最终 STEP；
- `logical_to_cad.json`：逻辑边 → CAD 边索引、面使用方向、参数区间、辅助顶点、周期 seam 规划、修复记录、shell 体积；
- `rejected_face_{id}.brep`：仅在该面 OCC 检查失败时写出。

### 11.1 阶段与产物

### 11.2 缓存与续跑

`cache.py::cache_key()` 包括：

```text
mesh hash + normalization + udf fingerprint + band_width + presence
+ Config（去掉 stop_after）+ bandbrep 全部 .py 的 code_hash
+ veudf v3 数据 schema + GEOMETRY_VERSION + veudf mesh oracle 源文件 hash
+ veudf sampling 源文件 hash
```

- 输出目录已有 `run.json` 时须使用 `--resume` 且 `cache_key` 一致。身份不匹配时报 `cache_mismatch`，应换新输出目录；
- STEP 路径的 UDF 身份包含源 STEP 哈希和 veudf 源码／运行环境指纹；
- 每个已登记 artifact 的 SHA-256 必须一致，否则 `cache_corrupt`；
- 已完成的 `solid_validated` 直接返回；
- 中间阶段可从 `run.json.stages` 接受缓存，并重新校验 `CenterFields` 与网格顺序；
- 所有缓存只用 JSON / NPZ，不使用 pickle。

### 11.3 时间预算与失败记录

- `deadline.py` 用 `ContextVar` 维护每例墙钟预算，默认 `sample_timeout_seconds=10800`；

- `quality.json` 记录 `status/stages/complete_solid`；
- 失败时记录 `failed_stage` 和 `error.code/message/details`，常见失败码包括：
  `invalid_mesh`、`mesh_scale`、`refinement_topology_changed`、`edge_localization_failed`、`vertex_mixed_support`、`edge_neighbors_unresolved`、`curve_distance_failed`、`curve_field_failed`、`edge_valley_unrepresented`、`surface_fit_failed`、`pcurve_fit_failed`、`cad_incidence_invalid`、`step_volume_changed` 等。

- 回放曲线评分：每条拟合曲线采 2049 点，与真值边折线支撑比较。

### 本批结果
